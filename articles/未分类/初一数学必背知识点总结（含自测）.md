各位好，我是嘟嘟，在合肥教了二十多年的数学。
**初一数学，是整个初中数学的地基。这一年学的东西，往后三年一直在用。**有理数、整式、方程、几何初步，看着不难，但概念多、细节碎，孩子很容易学一半漏一半。
 
这份知识点卡片，你可以直接打印出来，贴在书桌前。每个知识点后面配了自测题，学完一块就测一块。能做对，说明这块过了。做不对，回头再看一遍卡片，补上就行。
**一、有理数**
**知识点卡片**

1. 有理数定义：整数和分数统称有理数。

2. 有理数分类：整数包含正整数、0、负整数；分数包含正分数、负分数。

3. 数轴三要素：原点、正方向、单位长度。

4. 相反数：只有符号不同的两个数，互为相反数的两个数相加和为0。

5. 绝对值：数轴上一个点到原点的距离，结果一定是非负数。正数的绝对值是它本身，负数的绝对值是它的相反数，0的绝对值是0。

6. 倒数：乘积为1的两个数互为倒数，0没有倒数。

7. 有理数乘除法则：同号得正，异号得负。

8. 有理数乘方：多个相同数相乘；负数的偶数次幂为正数，负数的奇数次幂为负数。

9. 科学记数法：形式为a乘以10的n次方，其中a大于等于1且小于10。

**挖空自测**

1. ____和____统称有理数。

2. 数轴三要素：、、____。

3. 互为相反数的两个数和为____。

4. 绝对值是数轴上点到____的距离，结果一定是____数。

5. ____没有倒数。

6. 两数相乘，同号____，异号____。

7. 负数的____次幂为正，____次幂为负。

8. 科学记数法中a的范围是________。

标准答案

1. 整数、分数

2. 原点、正方向、单位长度

3. 0

4. 原点、非负

5. 0

6. 得正、得负

7. 偶、奇

8. 1≤a＜10

**二、整式的加减**
**知识点卡片**

1. 单项式：数或字母的积，单独一个数字、单独一个字母都是单项式。

2. 单项式系数：单项式前面的数字部分。

3. 单项式次数：单项式中所有字母的指数之和。

4. 多项式：多个单项式相加组成的式子。

5. 多项式次数：多项式里最高次项的次数。

6. 同类项：字母完全相同、相同字母的指数也完全相同。

7. 合并同类项法则：系数相加减，字母和字母的指数保持不变。

8. 去括号法则：括号前是正号，去括号不变号；括号前是负号，括号内全部变号。

**挖空自测**

1. 单项式____叫系数，________叫次数。

2. 多项式次数是____________。

3. 同类项要求：____相同、____________相同。

4. 合并同类项：____相加减，________不变。

5. 括号前是负号，去括号________。

标准答案

1. 数字部分、所有字母指数之和

2. 最高次项的次数

3. 字母、相同字母指数

4. 系数、字母和指数

5. 全部变号

**三、一元一次方程**
**知识点卡片**

1. 一元一次方程定义：只含一个未知数、未知数最高次数为1、整式方程。

2. 方程的解：能让方程左右两边相等的未知数的值。

3. 解方程标准五步：去分母、去括号、移项、合并同类项、系数化为1。

4. 移项核心规则：移项必须变号。

5. 常考应用模型：和差倍比问题、行程问题、工程问题、利润问题。

**挖空自测**

1. 一元一次方程：只含__个未知数，未知数次数为__，是____方程。

2. 解方程步骤：、、、、____。

3. 移项一定要________。

标准答案

1. 1、1、整式

2. 去分母、去括号、移项、合并同类项、系数化为1

3. 变号

**四、几何初步认识**
**知识点卡片**

1. 直线：无端点，可向两端无限延伸，两点确定一条直线。

2. 射线：一个端点，向一端无限延伸。

3. 线段：两个端点，可以测量长度，两点之间线段最短。

4. 线段中点：将线段平均分成相等两段的点。

5. 角度换算：1度等于60分，1分等于60秒。

6. 余角：两个角相加等于90度；补角：两个角相加等于180度。

7. 性质：同角或等角的余角相等，同角或等角的补角相等。

8. 对顶角相等，邻补角相加等于180度。

**挖空自测**

1. ____确定一条直线。

2. 两点之间____最短。

3. 余角和为____，补角和为____。

4. 同角的余角____，对顶角____。

标准答案

1. 两点

2. 线段

3. 90度、180度

4. 相等、相等

**五、相交线与平行线**
**知识点卡片**

1. 垂直定义：两条直线夹角为90度；过一点有且只有一条直线与已知直线垂直。

2. 垂线段性质：直线外一点到直线，垂线段最短。

3. 三线八角：同位角、内错角、同旁内角。

4. 平行公理：直线外一点，有且只有一条直线与已知直线平行。

5. 平行线判定：同位角相等则两直线平行；内错角相等则两直线平行；同旁内角互补则两直线平行。

6. 平行线性质：两直线平行，同位角相等、内错角相等、同旁内角互补。

**挖空自测**

1. 过一点____一条直线与已知直线垂直。

2. ____最短。

3. 同位角相等，两直线____。

4. 两直线平行，同旁内角____。

标准答案

1. 有且只有

2. 垂线段

3. 平行

4. 互补

**六、实数**
**知识点卡片**

1. 算术平方根：结果一定是非负数。

2. 平方根：正数有两个平方根，互为相反数；0的平方根是0。

3. 立方根：任意实数都有唯一立方根，正数立方根为正，负数立方根为负。

4. 无理数：无限不循环小数。

5. 实数：有理数和无理数统称实数，实数与数轴上的点一一对应。

**挖空自测**

1. 算术平方根一定是____数。

2. 正数有__个平方根，互为________。

3. ____都有唯一立方根。

4. 无理数是________小数。

5. 实数与数轴上的点________。

标准答案

1. 非负

2. 2、相反数

3. 任何数

4. 无限不循环

5. 一一对应

**七、平面直角坐标系**
**知识点卡片**

1. 象限符号：第一象限正正、第二象限负正、第三象限负负、第四象限正负。

2. 坐标轴上的点，不属于任何象限。

3. 对称规律：关于x轴对称，x不变y变号；关于y轴对称，y不变x变号；关于原点对称，x、y全部变号。

**挖空自测**

1. 第一象限（，），第二象限（，）。

2. x轴上点__坐标为0，y轴上点__坐标为0。

3. 关于x轴对称：__不变，__变号。

标准答案

1. +、+；-、+

2. 纵、横

3. x、y

**八、二元一次方程组**
**知识点卡片**

1. 二元一次方程：含有两个未知数，未知数最高次数为1的整式方程。

2. 两种解法：代入消元法、加减消元法。

3. 核心用途：解决含两组等量关系的实际应用题。

**挖空自测**

1. 二元一次方程含__个未知数，未知数次数为__。

2. 两种解法：、。

标准答案

1. 2、1

2. 代入消元法、加减消元法

**九、一元一次不等式与不等式组**
**知识点卡片**

1. 不等式性质：两边同时加减同一个数，不等号方向不变；两边同时乘除正数，不等号方向不变；两边同时乘除负数，不等号方向改变。

2. 不等式组解集口诀：同大取大、同小取小、大小小大中间找、大大小小无处找。

**挖空自测**

1. 不等式两边乘除负数，方向________。

2. 解集口诀：同大__、同小__、大小小大__、大大小小__。

标准答案

1. 改变

2. 取大、取小、中间找、无处找

**十、数据的收集与整理**
**知识点卡片**

1. 常用统计量：平均数、中位数、众数、方差。

2. 方差意义：方差越小，数据波动越小，数据越稳定。

**挖空自测**

1. 方差越小，数据越________。

标准答案

1. 稳定
