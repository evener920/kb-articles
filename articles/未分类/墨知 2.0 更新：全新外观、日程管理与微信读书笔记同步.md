# 墨知 2.0 更新：全新外观、日程管理与微信读书笔记同步
> 💡 备注属性未写入，可能是备注属性名称或者类型被修改了，建议将字段类型设置为 rich_text，可以在小程序-操作-修改文章数据库页面进行调整
> 💡 原文链接:[https://mp.weixin.qq.com/s?__biz=Mzk0ODY3NDYwMg==&mid=2247483810&idx=1&sn=20df31758dae0d25a263b3bd57bb4be1&chksm=c2dd08f65a67157c6e71e84808979e81b4326497b247ad934cf485c28d158a73c463e1be5513#rd](https://mp.weixin.qq.com/s?__biz=Mzk0ODY3NDYwMg%3D%3D&mid=2247483810&idx=1&sn=20df31758dae0d25a263b3bd57bb4be1&chksm=c2dd08f65a67157c6e71e84808979e81b4326497b247ad934cf485c28d158a73c463e1be5513#rd)
最近利用业余时间，结合日常使用需求给墨知做了一轮更新，主要是外观、写作体验、日程管理和微信读书笔记同步。
这个版本值得一个独立主页：mozi.yunz93.dev，欢迎访问。
### 全新的视觉风格
2.0 版本采用纸质白和金属灰两种外观，支持自定义主题色。
![](assets/414feb00ed728100-1.jpg)
![](assets/414feb00ed728100-2.jpg)
![](assets/414feb00ed728100-3.jpg)
### 小知助手
内置本地语义检索模型，可以在知识库中查找相关内容，也支持配置在线模型 API 进行智能问答。回答附有来源引用，点击即可回到笔记原文。
![](assets/414feb00ed728100-4.jpg)
### 微信读书笔记同步
支持将微信读书笔记同步到本地，保留划线和个人想法，继续整理成自己的笔记。
![](assets/414feb00ed728100-5.jpg)
![](assets/414feb00ed728100-6.jpg)
### Excalidraw 画板
Excalidraw 是我工作中常用的开源画图工具，现已集成到墨知，新建画板即可使用。
![](assets/414feb00ed728100-7.jpg)
### 待办与日程管理
在日记或项目笔记里，用 `@日期` 标记待办的到期日，也可以写成 `@YYYY-MM-DD HH:mm`，精确到分钟。输入 `@` 后可直接选择日期和时间，保存后在月历和清单里统一查看，点击待办即可返回原笔记。
```markdown
- [ ] 写完本周文章 @2026-11-12 15:00 
```
![](assets/414feb00ed728100-8.jpg)
![](assets/414feb00ed728100-9.jpg)
![](assets/414feb00ed728100-10.jpg)
指定时间的待办到点提醒；只写日期时，可以在设置里安排多个提醒时刻。开启后台运行后，关窗也能继续提醒，完全退出后停止。macOS 还可将待办单向同步到系统日历。
点击系统托盘图标，可以直接展开原生待办菜单，按日期和逾期状态查看事项，再打开来源笔记或返回墨知。
![](assets/414feb00ed728100-11.jpg)
### 专注模式
开启后进入全屏，隐藏侧边栏和工具栏，并突出当前段落，减少写作时的干扰。
![](assets/414feb00ed728100-12.jpg)
### 写作与发布
支持发布到配套的 Simple Blog 博客和微信公众号草稿箱，也能导出为 PDF、HTML 和长图。公众号草稿提交后，仍可在公众号平台继续编辑和发布。
![](assets/414feb00ed728100-13.jpg)
### 更好的写作体验
修复了编辑不连贯、部分 Markdown 语法渲染异常和中文输入时误关弹窗等问题，并优化了长文编辑、滚动和预览切换的体验。
![](assets/414feb00ed728100-14.gif)
Live 模式的编辑体验仍会继续优化，欢迎反馈使用中遇到的问题。
### 安装
在 macOS（Apple Silicon）上打开「终端」，复制执行：
```bash
curl -fsSL https://raw.githubusercontent.com/Yunz93/Mozi/main/scripts/install-macos.sh | bash 
```
脚本会自动下载最新版本，并安装到「应用程序」。
> 💡 Windows 和 Linux 用户可在 发布页 下载安装包；Linux 提供 x64 `.deb` 包。 三个平台均可在「设置 → 关于」检查更新，Linux 应用内升级需要系统授权。MacOS 做了相对全面的真机测试验证，Windows 和 Linux 主要通过云端环境和 CI 进行测试覆盖，有问题可以 issue 反馈。
