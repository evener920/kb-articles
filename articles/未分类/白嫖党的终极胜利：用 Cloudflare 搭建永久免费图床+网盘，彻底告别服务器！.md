如果你还在：

**搭建教程**
首先，访问 GitHub 搜索 CloudFlare-ImgBed 项目。点击 Fork，把它克隆到你自己的仓库里。这就是我们图床的心脏。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-1.png)
回到 Cloudflare 后台，点击 Workers 和 Pages，选择“创建项目”里的“Pages”。
关联你的 GitHub 帐号，选中刚才 Fork 的项目，点击“开始部署”。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-2.png)
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-3.png)
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-4.png)
| 配置项 | 值 | 说明 |
| 项目名称 | `cloudflare-imgbed`（或自定义） | 项目标识符 |
| 生产分支 | `main` | 生产环境分支 |
| 构建命令 | `npm install` | **重要：v2.0 新构建命令** |
| 构建输出目录 | `/frontend-dist` | 前端构建产物目录 |
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-5.png)
创建 R2 存储桶： 进入 R2 页面，新建一个存储桶，名字起叫 my-img-bed。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-6.png)
创建 KV 数据库： 进入 Workers KV，创建一个命名空间，名字填 img_url。这能保证你的图片链接永久有效。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-7.png)
回到 Cloudflare Pages 的项目设置，在配置里找到「绑定（Bindings）」这一项。
接着新增一个 KV 绑定：
- 变量名填写：img_url
- 绑定目标选择你刚刚创建的同名 KV 命名空间
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-8.png)
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-9.png)
添加 R2 绑定：变量名设为 img_r2，指向你的存储桶 my-img-bed。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-10.png)
👉 为了避免你的图床被别人随意使用，可以在环境变量里加一层“安全校验”：
- AUTH_CODE：相当于上传时用的密钥，没有这个码就不能上传文件
- BASIC_USER 和 BASIC_PASS：用来给后台管理页面加一层登录认证（账号 + 密码）
简单来说，就是添加三个变量 给上传入口和管理后台各上一把锁，防止被滥用。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-11.png)
配置完成后，点击重新部署。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-12.png)
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-13.png)
最后一步：点击自定义域，绑定你自己的域名。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-14.png)
搭建完成！现在你已经拥有一套支持拖拽上传、运行稳定、权限可控的专属图床系统，一切数据都掌握在自己手里。访问域名，输入自定义的密码进入即可。
![](assets/白嫖党的终极胜利：用 Cloudflare 搭建永久免费图床+网盘，彻底告别服务器！-15.png)
