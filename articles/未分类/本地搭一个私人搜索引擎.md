# 本地搭一个私人搜索引擎

每次用百度搜点敏感词，下午就收到了相关广告推送。
这不是巧合。搜索引擎记录你每一条查询词，打上标签，卖给广告商。你以为在搜索，其实是在被分析。
更麻烦的是，国内搜索引擎的结果越来越"商业化"——前三条全是竞价广告，真正有用的内容被压到第五页。
今天介绍的工具叫 **SearXNG**，一个可以跑在你自己电脑或服务器上的私人搜索引擎。搜索记录只存在本地，结果同时聚合 Google、Bing、DuckDuckGo 等十几个引擎，没有广告，没有追踪。
---
### 01SearXNG 是什么，和普通搜索有什么区别
SearXNG 是开源项目，本质是一个**元搜索引擎（Meta Search Engine）**。
它自己不抓取网页，而是同时向多个搜索引擎发请求，把结果汇总去重后返回给你。
关键在于：请求是从你的机器发出的，搜索引擎只看到一台服务器在查询，看不到你是谁。你的搜索历史也不会上传到任何地方，完全本地。
对比用 VPN 搜 Google——VPN 服务商还是能看到你查了什么，SearXNG 连这一层也省掉了。
---
### 02反常识的地方：结果比单独用 Google 还全
很多人觉得"聚合搜索"是凑合，其实恰恰相反。
**Google 对不同地区、不同账号登录状态返回的结果是不同的。** 未登录状态下，Google 会刻意限制某些专业内容的权重，把"安全"内容推上来。
SearXNG 同时调用 Google、Bing、Brave Search、DuckDuckGo、Wikipedia，还支持 GitHub、Stack Overflow 等垂直源，结果取并集。
实际用下来，搜技术问题时 Stack Overflow 的答案直接排在前面，不用再手动加 `site:stackoverflow.com`。
---
### 03怎么部署，半小时跑起来
部署方式推荐 **Docker**，三步搞定。
**前置条件：** 电脑已安装 Docker Desktop（Windows/Mac 均可），或者你有一台 Linux 服务器。
**第一步：创建配置目录**
```
mkdir searxng-docker && cd searxng-docker

```
**第二步：拉取官方 docker-compose 配置**
```
git clone https://github.com/searxng/searxng-docker.git .

```
**第三步：生成密钥并启动**
```
sed -i "s|ultrasecretkey|$(openssl rand -hex 32)|g" searxng/settings.yml
docker compose up -d

```
启动完成后，打开浏览器访问 `http://localhost:8080`，私人搜索引擎就跑起来了。
整个镜像约 200MB，内存占用稳定在 150MB 以下，老电脑也扛得住。
---
### 04三个值得单独说的配置
**1. 关闭所有日志**
默认配置会在本地留下查询日志。打开 `searxng/settings.yml`，找到 `server` 节点，把 `secret_key` 下方的 `bind_address` 改为仅本机访问（默认已是 `0.0.0.0`，建议改为 `127.0.0.1`），同时把 `search` 节点下的 `safe_search` 设为 `0`，解除过滤。
**2. 开启图片搜索**
默认只启用了网页搜索。在 `settings.yml` 里找到 `engines` 列表，把 `google images`、`bing images` 对应条目的 `disabled: true` 删掉，重启容器即可。
**3. 部署到家庭 NAS 或轻量服务器**
如果你有群晖、威联通，或者一台 20 块一个月的轻量云服务器，把 SearXNG 部署上去，再配合 **Cloudflare Tunnel** 穿透，就能在手机上用自己的搜索引擎，和用百度没有任何体验差别，但数据完全在你手里。
---
### 05把它设成浏览器默认搜索引擎
跑起来之后，最顺手的用法是替换浏览器默认搜索。
Chrome / Edge 操作路径：
1. 设置 → 搜索引擎 → 管理搜索引擎
1. 添加新搜索引擎，URL 填 
1. 设为默认
之后在地址栏直接输关键词，走的就是你自己的引擎。
Firefox 用户更简单，SearXNG 页面右键地址栏，直接有"添加搜索引擎"选项。
---
### 06和同类工具对比
- **Whoogle**：只聚合 Google，部署更简单，但结果单一
- **Brave Search**：有独立索引，不依赖 Google/Bing，但服务器在对方那里
- **DuckDuckGo**：不追踪但结果质量参差不齐，且服务器不在你手里
SearXNG 的优势是**完全自托管 + 多源聚合**，代价是需要自己维护，偶尔某个引擎的接口变了需要更新容器。
更新方式：
```
docker compose pull && docker compose up -d

```
一条命令，十秒钟完成。
