截图保存太麻烦？试试这款截图晾衣绳，截完直接挂绳上，随用随取，还能标注，拖进文件夹、拖进其他软件，想怎么用就怎么用，不用了还能挂在绳上晾一晾，省的“发霉”。
它就是**Tendedero**，开源、免费、体积小，双击一键安装。唯一的缺点是目前只支持苹果系统，可以先收藏一下（**文末有软件获取方式**）。

### 桌面，终于清爽了
把截图交给 **Tendedero**，它们就完全跳过桌面。 没有浮动缩略图。不用等五秒。拍下的瞬间即挂上绳，只有你拖出去的才会留下。
### 每个动作都有手势
| **手势** | **动作** |
| 单击 | 复制这张图。 |
| 长按 | 用「标记」打开。 |
| 双击 | 用「预览」打开。 |
| 用力点按 | 用「快速查看」看一眼。 |
| 拖进 App | 送一份副本过去。原图仍挂在绳上。 |
| 拖进文件夹 | 存在那儿。原图从绳上取下。 |
| 拖到废纸篓，或点叉 | 松手丢弃。 |
| 指针停在菜单栏 | 在那一块屏幕上放下绳子。 |
| 点击菜单栏任意处 | 把绳子收起来。 |
| ⌃ ⌥ T | 显示或隐藏绳子。可在菜单栏的「快捷键」中更改。 |
屏幕录制也会挂上绳，上面带一个播放按钮。按住即可剪辑。
同样的快捷键。同样的肌肉记忆。只是少了乱。
### 复制的图片也一样
按住 `⌃` 截图，或在「预览」中复制图片，它就会像其他截图一样挂上绳。 在菜单栏中打开「挂上复制的图片」，开启期间图标里的衬衫会被填满。只挂图片： 与文字或文件一起复制的内容，以及密码管理器标为私密的内容，都不会被挂上。
### 隐私设计
没有账号。不联网。无统计。 **Tendedero** 完全在你的 Mac 上运行，截图不会离开这台电脑。
