# 1324 个健身动作，装进一本能动的图鉴

朋友提起“哑铃侧平举”，你想查查动作长什么样。打开手机，搜到一排视频：有人讲技巧，有人讲训练安排，还有人先介绍了一段自己的课程。
你倒不是不想认真学，只是眼下想先弄明白：这是什么动作，用什么器械，大致怎么做。
这种时候，一本能随手查的动作图鉴，可能比继续刷视频更合适。
GitHub 上的开源项目 Exercises Dataset，整理了这样一套资料。名字听起来像给程序员用的，里面的内容，普通健身爱好者也能看懂不少。
## 名字有点技术，内容倒很直观
Dataset 翻译过来是“数据集”。不用被这个词劝退，你可以先把它理解成整理好的动作资料库。
截至本文核查，它包含 1324 条健身动作记录。每条都列出动作名称、身体部位、所需器械、目标肌肉和文字说明。按照项目介绍，还配有缩略图和 GIF 动图，分辨率为 180×180。
所以，它不是把一千多段视频丢进文件夹，等你自己翻。动作有分类，也有对应的信息，方便按需要查找。
项目还附带一个网页浏览页面，可以搜索、筛选，点开动作卡片看详情。不想研究数据文件，也可以通过这个页面了解内容。
不过，别把它想成另一个健身 App。它首先是一套动作资料，不是一门从头带你练的课程，也没有因此就具备私人教练的能力。
## 比动作多更重要的，是能按需要找
1324 个动作听着不少，但大多数人不需要挨个认识。
比如，你家里只有一对哑铃。与其在各种器械演示之间来回翻，不如先把器械筛选为 dumbbell，也就是哑铃，再看其中有哪些动作。
想了解胸部或肩部相关的动作，还可以结合身体部位、目标肌肉继续筛选。这个思路很朴素：先把不相关的资料排除，再逐个看自己关心的部分。
翻动图时，你能先对动作的外形和运动过程有个印象；需要了解细节，再读对应的文字步骤。它更适合用来查阅，而不是像短视频一样从头连续看下去。
有个分类容易误会：body weight，通常译作“自重”。它不代表完全不用器械。项目里的引体向上也属于这一类，但做这个动作仍需要相应设施。找居家动作时，不能只看标签，还得看具体动作需要什么条件。
筛选能帮你找到资料，至于筛出来的动作该不该放进自己的训练里，是下一回事。
## 有中文说明，但不是全中文教程
对中文读者来说，它比较实用的一点，是动作说明包含中文。
我核对了项目的数据文件：1324 条记录都带有中文说明，同时还有英语等其他语言，总共 10 种。至少在阅读步骤时，不必全程对着英文猜意思。
但“有中文说明”和“整个网站都能用中文”不是一回事。
动作名称、分类和器械标签仍有英文。当前网页的搜索范围也没有包含中文说明，不能指望输入一个中文动作名，就一定能搜到对应条目。更稳妥的办法，是先借助分类筛选，再进入详情查看中文步骤。
中文文本本身也要带着判断去读。资料里提供了翻译，并不意味着每一句都经过专业教练审核。如果文字表述不顺，或者你看完仍不明白动作细节，就需要再找可靠的讲解确认，而不是勉强照着理解。
所以，它降低了一部分阅读门槛，但还不是一本为中文新手专门编写的完整教材。
## 查得到，不等于适合照着练
动作资料回答的，主要是“这是什么”。
而“我适不适合做”“该从哪里开始”“一次练多少”，需要结合个人情况判断。一个写着目标肌肉、配着动图的条目，并不能替你完成这些决定。
同样，能看见演示，不代表有人在检查你的实际动作。把动作加入自己的训练安排之前，仍应弄清楚它的要求；有拿不准的地方，找合适的专业指导，比反复猜动图里的细节更有用。
本文也不据此推荐任何具体负重、组数或训练效果。图鉴可以辅助认识动作，但不能替代针对个人情况的指导。
## 适合当图鉴，不必当私教
如果你经常碰到不认识的动作，或者想按器械、部位查查资料，Exercises Dataset 值得了解。它把分散的动作信息整理到了一起，查阅的目的比较明确。
如果你期待的是“打开就告诉我今天怎么练”，它还不是那种产品。项目提供的浏览页面，也需要先取得仓库文件再打开，不能把代码仓库直接当成现成的在线健身服务。
最后提醒一句：开源不等于里面所有素材都能随意搬走。项目的代码、数据结构和文字说明采用 MIT 许可，但图片和动图版权归 Gym visual，另有使用条款。想把它们放进自己的文章、课程或产品，需要另查授权，不能因为能下载，就默认可以转载或商用。
把它当成一本动作词典就好：遇到陌生名字时翻一翻，先知道它是什么，再决定要不要继续学。
