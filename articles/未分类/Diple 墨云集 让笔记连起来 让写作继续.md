# Diple 墨云集 让笔记连起来 让写作继续

写一篇读书笔记，想起另一篇里的摘记；整理旅行计划，需要翻出之前列好的清单；一段随手写下的感想，后来成了文章的开头。
文字积累起来，我们也希望能更方便地找到它们之间的联系，把写好的内容分享出去，或带到另一台设备上继续写。
Diple 墨云集是一款支持 Markdown 与纯文本的笔记、写作 App。这次更新，让这些日常的小事，有了更顺手的做法。
## 让相关的笔记，彼此相连
读完一本书，摘记和感想可能分散在几篇文稿里。写到某个观点时，如果能直接翻到相关的那一篇，思路也更容易接下去。
现在，可以在 Markdown 文稿中加入指向其他文稿的链接。把「读书随想」连到相关摘记，把「旅行计划」连到行李清单，读到这里，点一下就能过去。
打开被引用的文稿，还能通过反向链接，看到哪些文章提到了它，并回到引用的位置。
一段文字被用在了哪里，一个想法后来写出了什么，回头翻看时，也就多了几条线索。
![](assets/416feb00ed72813e-1.png)
## 把喜欢的文字，分享出去
写好一段随笔，想发给朋友看看；整理完一篇游记，想让照片和文字一起留下来。
现在，可以把文稿按阅读时的样子导出为图片，保存到相册后再分享。需要打印或交给别人修改时，也可以选择 PDF、Word 等格式。
如果对方也使用 Diple，还可以导出为新的Diple 文稿，把正文和其中的本地图片、视频装进同一个文件。换一台设备打开，图文一起导入，还能接着编辑。
![](assets/416feb00ed72813e-2.png)
## 换一台设备，接着写
日记写久了，读书笔记攒多了，换手机时也希望把它们好好带过去，连同整理过的文件夹和合集一起。
Diple 的数据迁移可以让附近的两台设备直接传输内容。文稿中的本地图片、备注和历史版本，也会一并保留，不用重新整理。
传输无需使用 iCloud，也不占用 iCloud 存储空间。
想另外留一份存档，还可以生成数据备份，保存到自己选择的位置，之后在本机或另一台设备上恢复。备份也能设置密码，让积累的文字多一份妥善保存的副本。
![](assets/416feb00ed72813e-3.png)
## 想找的时候，更快找到
临出门，想看一眼旅行清单；聊天时，忽然想起自己写过的一段话。
开启相关设置后，在 iPhone 的系统搜索里输入文稿标题或正文关键词，就能找到对应内容，也可以搜索合集名称，直接打开继续读。
想到一句话想先记下来，也可以请 Siri 帮忙新建文稿，或把文字追加到已有的记录里。这些动作还能放进自己的快捷指令，让随手记录更方便。
受保护的内容不会向系统搜索或 Siri 开放。
![](assets/416feb00ed72813e-4.png)
## 把记录，慢慢写下去
做旅行预算时，表格可以快速求和、增减行列，较宽的表格也能左右滑动查看。读到一半的长文，开启「记录滚动」后，下次打开还能回到上次的位置。
希望Diple 墨云集能陪你把想法记下来，让相关的文字彼此连接，也让那些已经写下的内容，值得常常回来翻一翻。
在 App Store 搜索「Diple」或「墨云集」，即可找到Diple 墨云集 · Markdown 笔记。
