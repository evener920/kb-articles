# GitHub淘金记｜20.2K Star，电子书变有声书，打造自己的喜马拉雅

开车、健身、做饭、通勤，这些时间你在干什么？
有一批人选择听书。喜马拉雅上有声书的月活用户超过 1 亿，Audible 在国外是亚马逊最赚钱的内容业务之一。但一本书的有声版制作成本不低，录音、剪辑、上架，专业团队做一本要好几天。
ebook2audiobook 把这件事变成了一行命令：给它一个电子书文件，它自动把文字转成语音，生成完整的有声书音频文件。目前 GitHub 上 20.2K star。
**支持声音克隆**
普通 TTS 转出来的声音有明显的机器腔，听着累。ebook2audiobook 支持用你自己的声音或者任意参考音频做克隆——准备 15 秒的参考音频，模型会模仿这个声音把整本书读完。克隆效果比通用 TTS 自然得多，听起来更像真人朗读。
支持 100 多种语言，中文表现也不错。电子书格式支持 epub、pdf、mobi 等主流格式。
**变现路径：公版书有声版**
版权保护期超过 50 年（或作者去世 70 年后）的书是公版书，任何人都可以自由使用。中文有大量公版书：四大名著、鲁迅全集、古典诗词，这些书的有声版在喜马拉雅上都有人在卖，售价几元到几十元一本。
用 ebook2audiobook 批量把公版书转成有声版，上架到喜马拉雅、荔枝 FM 等平台。成本几乎只有时间，每本书的制作时间取决于字数和机器性能，通常一两个小时可以出一本。
**真实的限制**
声音克隆效果和参考音频质量直接相关，参考音频嘈杂或者发音不清晰，克隆出来也会不稳定。转长篇书（比如几十万字的小说）需要较长的运行时间，推荐在有 GPU 的机器上跑。另外平台对 AI 生成有声内容的审核尺度在收紧，上架前要确认平台当前的具体规则。
有声书赛道还没饱和，公版书的有声版存量也还远没有被覆盖完，现在入场算早期。 
**自用场景**
不考虑变现，只是想把自己收藏的几百本电子书转成可以边开车边听的格式，ebook2audiobook 也是很实用的工具。很多人买了大量电子书从来没读完，因为没有整块时间坐下来读。转成有声书塞进手机，通勤路上消化，是完全不同的体验。
输出格式支持 m4b，这是苹果有声书的标准格式，里面可以嵌入章节标记，导入苹果"图书"App 后会自动按章节分割，跟在 Audible 上买的有声书体验一样。
