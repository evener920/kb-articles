# 数轴上的“距离博弈”——绝对值最值问题

课堂上，我在黑板上写了一道题：
求 |x-1| + |x-3| + |x+4| 的最小值。
全班安静了30秒，然后开始各种猜测：x=0时？x=1时？x=3时？
有个孩子举手说：“老师，这是不是要用分类讨论？”
我问：“你觉得该如何分类？
“按零点分段啊。x<-4, -4≤x<1, 1≤x<3, x≥3，四段分别讨论。”
“好，咱一起来试试。”
孩子们开始尝试。五分钟后，有个同学抬起头：“老师，我算出来了，x=1时最小值是7，但写了半页纸。”
我屏展给全班同学，他进行着同步讲解，我微笑着：“逻辑很调条理，讲解的也很清晰，看来半页纸是对的，但有没有更快的方法？”
全班又安静了。
我在黑板上画了一条数轴，标出三个点：-4、1、3。然后在数轴上方写了三个式子：
｜x｜
｜x-1｜
｜x-3｜
｜x+4｜
提出一个问题：它们分别表示什么几何意义？
｜x｜=｜x-0｜= x到0的距离
|x-1| = 点x到1的距离
|x-3| = 点x到3的距离
|x+4| = |x-(-4)| = 点x到-4的距离

所以原式 = **点x到三个定点的总距离**。 问题变成：在数轴上找一个点x，使得到-4、1、3三个点的距离之和最短。
“现在，不要算，用眼睛看。”
### 第一步：|x-a| 的本质是“距离”
课本上绝对值的定义是“一个数在数轴上对应的点到原点的距离”。
但这只是起点。**|x-a| 的真正含义是：数轴上点x到点a的距离。**不管x在a的左边还是右边，距离都是非负的。
**关键转换：**
|x| = x到0的距离
|x-3| = x到3的距离
|x+5| = |x-(-5)| = x到-5的距离

如此，**所有绝对值都可以翻译成“距离”**。
一旦翻译成距离，问题就从"代数运算"变成了"几何观察"。
这个转换一旦建立，很多“难题”就变成了“看图说话”。
### 第二步：距离之和最短——“中间点”的几何直觉
回到那道题：|x-1| + |x-3| + |x+4|。
画一条数轴，标出-4、1、3三个点。让“点x”从最左边开始，慢慢向右移动。
**课堂实录：“点x”走一走**

我让一个学生扮演“点x”，站在教室最左边（代表数轴负无穷），然后一步一步向右边走。

每走一步，全班一起喊：“到-4的距离 + 到1的距离 + 到3的距离 = 多少？”

数据记录：
x = -5：1 + 6 + 8 = 15
x = -4：0 + 5 + 7 = 12
x = -2：2 + 3 + 5 = 10
x = 0：4 + 1 + 3 = 8
x = 1：5 + 0 + 2 = 7 ← 最小
x = 2：6 + 1 + 1 = 8
x = 3：7 + 2 + 0 = 9
x = 5：9 + 4 + 2 = 15

学生自己发现：“x从左边走过来，总距离一直在减小，走到1的时候最小，再往前走又变大了！”

我问：“为什么是1？”
“因为1在三个点的中间！”
“如果改成 |x-1| + |x-3| + |x-5| + |x-7| 呢？四个点。”
学生愣了一下，然后在数轴上标出1、3、5、7。
“中间是3和5之间，随便哪个点都行？”
“对。3到5之间任意一点，总距离都是最小的。”
五个点呢？六个呢？…
**奇点偶段的本质：**
不是口诀，是**数轴上距离博弈的均衡点**。

奇数个点：中间那个点左边和右边的点数“大致平衡”，向任何方向移动都会让某一侧的距离增长超过另一侧的减少。所以**中间点唯一**。

偶数个点：中间那一段上的任意一点，左右两侧的点数都平衡，所以**中间那一段上的所有点都是最小值**。
这个结论不需要死记硬背，让孩子在数轴上“走一圈”就能看见。
### 第三步：距离之差最大——“跑到一端”的几何直觉
理解了“距离之和最短”，再看“距离之差最大”就很容易了。
图1上的四道题：
① |x+2| - |x-1| 的最大值
② |x+3| - |x-2| 的最大值
③ |x+5| - |x+7| 的最大值
④ |x-5| - |x+1| 的最大值
转换一下：|x+2| = x到-2的距离，|x-1| = x到1的距离。
所以 |x+2| - |x-1| 就是：**点x到-2的距离 减去 点x到1的距离**。
画数轴，标出-2和1。让点x从最左边走到最右边：
**枚举观察：**
x = -2：到-2的距离=0，到1的距离=3， 差 = 0-3 = -3
x = -1：到-2的距离=1，到1的距离=2， 差 = 1-2 = -1
x = 0：到-2的距离=2，到1的距离=1， 差 = 2-1 = 1
x = 1：到-2的距离=3，到1的距离=0， 差 = 3-0 = 3
x = 2：到-2的距离=4，到1的距离=1， 差 = 4-1 = 3 …
所以x≥1时差值恒为3；x≤-2时差值恒为-3。
最大值=3，在x≥1时取得；最小值=-3，在x≤-2时取得。

**结论：**差值的最大值 = 两个定点之间的距离 = |-2-1| = 3。
当点x跑到“较远端”的外侧时，到近点的距离=0，到远点的距离=两点间距，差值拉满。
**“和”与“差”的对照：**
|x-a| + |x-b| → 找**中间**，最小值=|a-b|（两点之间线段最短）
|x-a| - |x-b| → 找**外侧**，最大值=|a-b|（跑到一端，距离差拉满）

一个求“最短路径”，一个求“距离差最大”。核心都是**数轴上的距离关系**。
### 课堂实践：“先算后画”对比法
为了让学生真正感受到几何方法的威力，我做了一个对比实验：
**实验设计：**
同一道题，用两种方法解，记录时间和步骤数。

**题目：**|x-2| + |x-6| + |x+3| 的最小值。

**方法一：分类讨论（代数法）**
1. 找零点：x=2, x=6, x=-3
2. 分四段：x<-3, -3≤x<2, 2≤x<6, x≥6
3. 逐段去绝对值：
x<-3：-(x-2)-(x-6)-(x+3) = -3x+5，单调递减
-3≤x<2：-(x-2)-(x-6)+(x+3) = -x+11，单调递减
2≤x<6：(x-2)-(x-6)+(x+3) = x+7，单调递增
x≥6：(x-2)+(x-6)+(x+3) = 3x-5，单调递增
4. 找最小值：在x=2处，左边递减、右边递增，所以x=2时最小。
5. 代入：|2-2|+|2-6|+|2+3| = 0+4+5 = 9。

平均用时：5-8分钟，步骤数：15步以上。

**方法二：画数轴（几何法）**
1. 画数轴，标出-3、2、6。
2. 观察：三个点，奇数个，中间点是2。
3. 最小值 = 到三个点的距离和 = 0+4+5 = 9。

平均用时：30秒，步骤数：3步。

**全班统计：**
代数法，平均用时6分23秒，错误率31%。
几何法，平均用时42秒，错误率3%。

有个学生说：“我以前觉得分类讨论才是'正规方法'，画图是'偷懒'。现在发现，画图才是更接近本质的方法。”
### 数轴动点：三大公式的几何本质
图3展示了数轴动点的三大公式。这三个公式不是孤立的知识点，是**数轴上的“度量系统”**。
**公式一：AB = |a-b|**
两点之间的距离。几何意义：数轴上两个点之间的线段长度。

**公式二：位置 = 起点 ± 速度×时间**
右加左减。几何意义：点在数轴上移动，向右远离原点用加，向左靠近原点用减。

**公式三：m = (a+b)/2**
中点公式。几何意义：两个点的对称中心，到两端距离相等。
我在课堂上用“相遇问题”串联了这三个公式：
**课堂活动：数轴上的相遇**

A在-3，B在5。A以每秒2单位向右，B以每秒1单位向左。

1. 初始距离 = |5-(-3)| = 8（公式一）
2. 相对速度 = 2+1 = 3（相向而行，速度相加）
3. 相遇时间 = 8÷3 = 8/3 秒
4. A的位置 = -3 + 2×(8/3) = 7/3（公式二）
5. B的位置 = 5 - 1×(8/3) = 7/3（公式二）
6. 验证：中点 = (-3+5)/2 = 1，但相遇点是7/3 ≈ 2.33，不是中点。

为什么不是中点？因为速度不同！
只有当**速度相同且相向而行**时，相遇点才是中点。

这个发现让学生理解了：公式不是死记硬背的，是**解决具体问题时选择的工具**。
### 与家长共勉的“三问”检查法
检查孩子是否真正理解了绝对值的几何意义，问三个问题：
**问题一：|x-3| + |x+5| 的最小值是多少？**
如果孩子能画出数轴，标出3和-5，说出“最小值是8”，并且知道x在-5到3之间时都能取到最小值——理解了。
如果孩子直接背“偶数个取中间段，答案是8”——需要追问原理。

**问题二：|x-3| - |x+5| 的最大值是多少？**
如果孩子能说出“最大值是8，当x在-5左边时取得”——理解了。
如果孩子说“用奇点偶段法”——说明混淆了“和”与“差”的方法。

**问题三：数轴上A表示-2，B表示4，A以每秒3单位向右，B以每秒1单位向左，几秒后相遇？**
如果孩子能列出：距离=6，速度和=4，时间=1.5秒，位置=-2+4.5=2.5——三大公式用对了。
如果孩子只背公式但不知道怎么选——需要更多“数轴走动”的练习。
### 为什么“画图”比“计算”更接近本质
有学生问我："奇点偶段法考试能用吗？会不会被扣分？"
我的回答是：**能用，但前提是理解原理。**
如果能画出数轴，标出零点，解释“为什么取中间点/中间段”，那么用这个方法解题是完全正确的——因为ta在用**几何直观**解决问题，不是在套公式。
但如果孩子只是背了“奇数取中点，偶数取中段”，考试时直接写结论，一旦题目变形（比如加了系数、变了区间），就会栽跟头。
**真正可靠的方法：**
1. 把所有绝对值转成“到某点的距离”
2. 在数轴上标出所有固定点
3. 让“动点x”在数轴上走一圈，观察和/差的变化规律
4. 找到均衡点/极值点
5. 得出结论

这个方法比“奇点偶段”慢一点，但**不会错、不会忘、不怕变形**。
更重要的是，它让孩子理解了**代数式背后的几何图形**——这是初中数学最重要的思维升级之一。
