# 用AI将《史记》57万字转化为可交互、可探索的知识图谱，让两千年前的文字像代码一样可以语法高亮、跳转、搜索、推理

> 原文链接:[https://mp.weixin.qq.com/s/K_JeXJyQyOnmWMK6mLnG_Q](https://mp.weixin.qq.com/s/K_JeXJyQyOnmWMK6mLnG_Q)
**史记知识库**（shiji-kb）是由鲍捷开发、Anthropic 的 Claude Code（以 Claude Sonnet 4.5 / Opus 4.6 为主力模型）作为 AI 协作者共同打造的大型古籍知识工程项目，累计消耗约 55 亿 tokens 与 120 小时人机协作。
项目将《史记》57 万字原文转化为可交互、可探索的结构化知识图谱，实现 22 类实体语法高亮、概念跳转、段落精确分享（Purple Numbers）、全局搜索与辅助推理。
项目全管线无传统程序硬编码，完全由自然语言撰写的 SKILL 指导 AI 执行，并沉淀出一套可复用的大规模古籍数字化方法论。
![](assets/409feb00ed728158-1.jpg)
#### 要点
- **规模与数据**：项目完成了130篇《史记》全文标注，产出14,065个实体（126,441次标注，22类）、3,198个历史事件（98.7%标注公元纪年）、7,637条事件关系（9种类型），以及130条交互式时间线（"史记地铁图"）。Wiki 系统页面数已突破 20,830 页，知识量约 81 万，集成了 600+ 谭其骧历史地图自动截图配图与全量重建的 20 国君主世系表。
- **标注质量经过多轮反思迭代**：实体标注经过4轮按章审查，累计修正约28,000处；事件时间经过5轮反思迭代，修正约2,100处误差。每轮修正量递减，表明已近收敛。
- **核心方法论：Agentic Ontology**：提出"Agent驱动本体"范式——本体不再由专家自上而下设计，而是AI从原始文本中自下而上提取，再由人类修剪校准。SKILL 体系包含 14 个元技能与 89 个管线技能（2026 年 3 月发布的 2 本 PDF 合集共 863 页，收录了 14 个元技能与 40 个管线技能的快照）。
- **自动化的AI运维机制**：Butler Agent 自主维护 Wiki，累计运行 12,000+ 轮，配备三层反思机制（流程反思、图式反思、类型审计），每轮执行 1 个原子操作，每 23 轮批量提交一次。
- **从数据涌现的跨章洞见**：知识图谱构建过程中发现了 20+ 个跨章节深层规律（如“征服-治理倒转”“边缘优势”“宽恕悖论”等），并产出长平之战财政计算、冯谖烧券买义经济学分析等 12 个史源推理深度案例（共 10.7 万字）。
- **特色阅读与辅助体验**：提供 22 类实体的语法高亮显示（支持右上角齿轮关闭并持久化保存偏好）、句间语义排版、三家注对齐，以及精确到段落的 Purple Numbers 引用分享功能。
#### 上手
- **零门槛在线阅读**：无需任何安装和账号，直接打开主站 baojie.github.io/shiji-kb 或备用站 shiji.memify.wiki （国内更稳定）即可体验语法高亮阅读、地铁图、Wiki等全部功能。
- **本地部署与运行**：需要Python 3环境，通过 git clone 下载仓库，执行 pip install -r requirements.txt 安装依赖，运行 python3 wiki/server/serve.py wiki/public 8000 即可在本地启动。
