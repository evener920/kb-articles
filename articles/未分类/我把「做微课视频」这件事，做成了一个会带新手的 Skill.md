### 做微课视频，最花时间的从来不是「讲什么」
做一节微课，写脚本往往两小时就能搞定；真正耗人的，是后面这一长串——
找配图、做动画、对时间轴、调音量、找人配音、一遍遍导出看效果……
一条 1 分钟的讲解视频，从脚本到成片，常常要折腾一两天。更别说做第二个、第三个主题时，前面踩过的坑还要再踩一遍。
所以我做了这件事：把「知识动画讲解视频」的整套制作流程，做成一个 **AI Skill**。
你只要给一个主题，或者一份脚本，剩下的它来。
---
### 先看一条 1 分钟的介绍
【视频：知识动画讲解 · Skill 介绍（约 56 秒）】本视频也是由该技能制作，一键直出。
---
### 这个 Skill 是什么？
一句话：**一个会「带新手」的知识动画讲解视频制作助手。**
它不是又一个「输入一句话、随机生成一段视频」的黑盒，而是一套**可复现、可修改、可换配音**的完整生产流程：
- 输入：一个主题 / 一份脚本
- 中间：自动拆分为分镜，程序化绘制画面，配音、配乐、混音、合片
- 输出：一条 16:9 的 MP4 成片 + 可复现的工程文件 + 质检报告
最重要的是：**第一次使用，它会手把手教你准备素材；之后再用，直接开工。**
---
### 三个我最喜欢的设计
#### ① 首次使用有引导，第二次自动跳过
第一次打开时，它会按步骤引导你准备素材：
脚本或主题 → 视觉风格 → 配音方案 → 背景音乐 → 输出偏好 → 环境体检 → 试做样片
每一步都会保存，中途离开可以接着做；全部完成后，它会记住你的偏好，直接开始做第一条视频。
以后再打开：跳过引导，问一句「这次讲什么」，直接开工。
#### ② 配音不绑定某一家服务
配音可以是你自己的录音（最推荐，音色最可控），也可以接入：
- OpenAI 兼容的任意 TTS 服务
- ListenHub（可选副选项，中文音色丰富）
- 系统自带语音（离线兜底）
背景音乐同样自由：自备、生成、或者干脆不用。
API Key 只放环境变量，不写进任何文件——这一点是硬性约束。
#### ③ 画面程序化渲染，改文案不用重拍
画面不是一次性生成的视频素材，而是用代码逐帧绘制的动画。这意味着：
- 改一句旁白，只需重新生成对应音频 + 重新渲染，不用重拍
- 换一个配音音色，画面母版可以完全复用
- 成片自动混音（人声与 BGM 分级）、自动质检（时长 / 流参数 / 旁白到位 / 冻结帧）
---
### 它是怎么工作的？
主题/脚本 → 分镜表 → 程序化动画 → 配音 & 配乐 → 混音合片 → 自动质检 → 成片
整条流水线里，AI 负责拆分镜、写画面、生成配音、做质检；你负责定主题、审样片、提修改。
---
### 怎么用？三步
**第一步：安装**
把 Skill 压缩包解压到你的 AI 工具的 skills 目录（不同工具路径略有差异）。
**第二步：第一次使用**
对 AI 说「用知识动画讲解做一个关于 XX 的视频」，它会开始引导：准备脚本、选风格、定配音、试做样片。
**第三步：以后每次**
直接说主题或贴脚本，它会沿用上次的偏好，跳过引导直接制作。
**环境要求**：电脑上有 Python 和 ffmpeg；配音若用 TTS，需要准备对应的 API Key（不想用 API 也可以用自己的录音）。
---
### 适合谁？
- 老师、教研员：把知识点做成微课、讲解视频
- 知识博主 / 科普作者：批量制作同一风格的讲解视频
- 培训/产品团队：把 SOP、课程、产品说明做成动画
- 想用 AI 做视频，但受够了「一次性生成、改不动」的人
**不适合**：需要真人出镜、实拍、生成式 AI 视频镜头的场景。
