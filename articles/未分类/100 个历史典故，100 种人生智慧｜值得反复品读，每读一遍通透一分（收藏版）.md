**导　语**
人生走过一些路，经历一些事，才会慢慢明白：许多困扰我们的问题，前人早已遇见；许多今天仍在发生的人情冷暖，历史中也曾反复上演。
有人坚守操守，面对诱惑不肯低头；有人知恩图报，一诺千金；有人忍辱负重，在困境中等待转机；也有人机关算尽，最终败给自己的贪婪与傲慢。
一个典故，往往藏着一段真实或流传已久的故事。故事里有人的选择，有命运的转折，也有世事的得失。读懂它们，我们便能从前人的经历中，看清人情世故，理解进退取舍，也重新审视自己的生活。
中国历史典故浩如烟海。这里精选一百个广为流传的经典故事，从修身、处世、谋略、识人、家风、治学到人生哲理，读一段故事，悟一种智慧。愿我们在历史的回响中，看见人性的复杂，也找到面对现实的清醒与从容。
**壹**
**修身养性**
_一个人的品格，藏在无人看见的地方_
──── ◆ ────
| **01** | **梨虽无主，我心有主****故事　**元代许衡曾在盛夏赶路，途中口渴难耐，路旁恰好有一棵梨树，树上结满了果实。同行的人纷纷摘梨解渴，唯独许衡坐在树下不为所动。有人劝他，眼下兵荒马乱，梨树早已无人看管，摘几个又有什么关系？许衡回答：梨虽无主，我心有主。**解读　**这句话，道出了一个人真正的修养。外界有没有约束，别人能不能看见，都不应该成为判断行为对错的标准。一个人能够守住底线，靠的是内心的准则。诱惑面前的选择，往往比众人面前的表现，更能看清一个人的品格。 |
| **02** | **不欺暗室****故事　**春秋时期，卫国大夫蘧伯玉以品行端正闻名。有一次，卫灵公夜间召见他，蘧伯玉乘车前往，途中经过宫门时，按照礼制下车步行。即使夜色深沉，周围无人，他依然严格遵守礼仪。后人以“不欺暗室”称赞这种独处时也能守住操守的品格。**解读　**一个人的底线，往往在无人监督的时候才真正显现。公开场合的体面并不难维持，难的是独处时依然不放纵自己。真正可靠的人，心里有尺，做事有度，不需要时时有人提醒。 |
| **03** | **四知拒金****故事　**东汉时期，杨震赴任东莱太守，途经昌邑。曾经受他举荐的县令王密，夜里带着黄金前来拜访。王密说：“暮夜无知者。”意思是深更半夜，没有人会知道。杨震却回答：“天知，神知，我知，子知。何谓无知？”最终拒绝了黄金。**解读　**世上有些事情，看似无人知晓，自己却永远无法欺骗自己。一个人能否抵挡诱惑，决定了他能走多远。贪图一时好处，可能失去长久的安宁；守住原则，才能在无人看见的地方，也坦然面对自己。 |
| **04** | **精卫填海****故事　**传说炎帝的小女儿女娃在东海游玩时不幸溺亡，死后化为精卫鸟。她常常衔着西山的木石，飞向东海，想要填平大海。大海辽阔无边，木石微不足道，可精卫始终没有停止。**解读　**这个故事流传千年，成为坚韧不屈的象征。人生中有些目标看起来遥不可及，有些努力也未必马上得到回应。真正重要的，是在知道困难存在之后，依然愿意迈出下一步。坚持未必保证成功，却能让一个人不轻易向命运低头。 |
| **05** | **愚公移山****故事　**传说太行、王屋两座大山挡住了愚公家门前的道路，愚公决定带领家人挖山开路。有人嘲笑他年纪大、山又高，根本不可能完成。愚公回答，自己死后还有儿子，儿子还有孙子，子子孙孙无穷无尽，而山不会增加，终有一天能够挖平。这个故事后来成为坚持不懈、迎难而上的经典寓言。**解读　**人生最怕的，是还没有开始，就先被困难吓退。很多事情确实不可能一蹴而就，但只要方向正确，每天向前一点，时间就会成为自己的力量。眼前看不到结果，不代表努力毫无意义。 |
| **06** | **夸父逐日****故事　**上古传说中，夸父看见太阳东升西落，决心追赶太阳，想要弄清太阳运行的规律。他一路奔跑，口渴难耐，饮尽黄河、渭水之水，仍然无法解渴，最终倒在追日途中，手杖化作桃林。**解读　**夸父逐日，是一个充满悲壮色彩的故事。人总会有超越自身能力的渴望，也会有明知艰难仍然向前的勇气。理想值得追求，但也要懂得认识自身的边界。勇敢令人敬佩，清醒同样重要。 |
| **07** | **苏武牧羊****故事　**西汉时期，苏武奉命出使匈奴，却因局势变化被扣留。匈奴多次劝降，甚至以严酷手段逼迫他屈服，苏武始终不肯投降。后来，他被流放到北海牧羊，生活极其艰苦。多年过去，苏武仍然坚守汉朝使臣的身份，直到汉匈关系缓和，才得以返回故国。**解读　**十九年的风雪与孤独，没有磨掉他的气节。一个人的尊严，有时需要用漫长岁月去守护。环境可以改变生活，却不应该轻易改变一个人的信念。真正的坚守，往往发生在无人喝彩的漫长岁月里。 |
| **08** | **陶母退鱼****故事　**东晋名将陶侃年轻时曾任浔阳督邮。一次，他派人给母亲送去一坛腌鱼。陶母收到后，原封不动退还，并写信责备他：你身为官员，拿公家的东西送给我，不但没有让我高兴，反而增加了我的忧虑。陶母以严格家教提醒儿子，做官必须清白。**解读　**父母留给子女最珍贵的财富，往往是做人的规矩。一个家庭的家风，体现在日常细节里，也会影响一个人面对利益时的选择。真正的疼爱，是教会孩子如何堂堂正正地做人。 |
| **09** | **季札挂剑****故事　**春秋时期，吴国公子季札出使途中经过徐国。徐君非常喜欢季札佩戴的宝剑，却没有开口索要。季札看出了他的心意，心中已经决定，等出使归来后将剑赠给徐君。后来季札返回徐国时，徐君已经去世。季札仍然来到徐君墓前，将宝剑挂在墓旁，以兑现心中的承诺。**解读　**有些承诺，未必有人监督，也未必有人追问，但一个真正重诺的人，会把它放在心上。人与人之间的信任，正是由这些看似微小的坚持一点点建立起来的。 |
| **10** | **一诺千金****故事　**秦末汉初，楚人季布以守信闻名。只要答应别人的事情，他就会尽力做到，因此民间流传着“得黄金百斤，不如得季布一诺”的说法。后来季布遭到追捕，仍有许多人冒着风险保护他。一个人的信用，成为他危难时最有力的依靠。**解读　**金钱可以换来一时便利，信用却需要多年积累。一个人说过的话能不能兑现，答应的事情能不能做到，决定了别人是否愿意长期信任他。信誉看不见、摸不着，却常常比财富更有分量。 |
**贰**
**处世智慧**
_人与人之间，最难得的是分寸与真心_
──── ◆ ────
| **11** | **负荆请罪****故事　**战国时期，赵国大将廉颇认为蔺相如凭借口舌之功位居自己之上，心中不服，扬言要当面羞辱他。蔺相如得知后，处处避让。有人不解，他解释说，秦国之所以不敢轻易进犯赵国，正是因为有自己和廉颇两人在。如果两人争斗，受损的只会是国家。廉颇听闻后深受触动，脱去上衣，背负荆条，亲自登门谢罪。**解读　**真正有格局的人，懂得把眼光放得更远。争一时输赢，也许能得到短暂的痛快，却可能失去更重要的东西。能放下身段承认错误，也是一种难得的勇气。 |
| **12** | **绝缨之宴****故事　**春秋时期，楚庄王举行宴会，席间灯烛突然熄灭。一名臣子趁黑暗拉扯王妃衣袖，王妃扯断了他的帽缨，并请求楚庄王点灯查明。楚庄王却让所有人都扯下帽缨，随后才重新点灯，使那名臣子免于当众受辱。后来楚国出征，有一位将领奋勇杀敌，立下大功，正是当年失礼的臣子。**解读　**楚庄王没有因一时冒犯而毁掉一个人的尊严，也因此赢得了臣下的感念。待人处世，有时给别人留一分余地，日后便可能收获一份真心。宽容并非纵容，而是懂得在合适的时候给人改过的机会。 |
| **13** | **鸡鸣狗盗****故事　**战国时期，齐国孟尝君田文被秦昭王扣留。为了逃脱，他的门客中有人擅长学狗叫，潜入秦宫偷回狐白裘；另有人模仿鸡鸣，引得城门守卫提前开门，帮助孟尝君逃出函谷关。两名门客看似不起眼，却在关键时刻发挥了作用。**解读　**一个人的价值，不能只用表面的身份和能力衡量。世上有各种各样的人才，有人擅长谋划，有人精于细节，也有人在危急关头能够解决别人解决不了的问题。识人用人，贵在看见不同人的长处。 |
| **14** | **千万买邻****故事　**南朝宋时，吕僧珍为官清正，深受百姓敬重。有人想要在他住宅附近买地建房，吕僧珍得知后，认为邻里关系远比房屋本身珍贵。后世流传“千万买邻”的说法，用来形容良好邻里关系的价值。**解读　**房屋可以买卖，邻里却要长久相处。生活中的许多幸福，来自身边人的善意与体谅。一个好邻居、一份可靠的关系，有时比昂贵的物质更能让人安心。 |
| **15** | **割席分坐****故事　**东汉时期，管宁与华歆曾经一同读书。一次，两人坐在席上，外面有人乘坐华丽车马经过，华歆起身出去观看，管宁却依旧读书。事后，管宁割开两人共坐的席子，表示从此不再与华歆为友。后世以“割席绝交”形容因志趣不同而断绝交往。**解读　**人与人相处，最初可能因为兴趣相投走到一起，时间久了，才会发现彼此的价值观和人生方向是否一致。关系可以珍惜，但也要有自己的判断。并非所有相识，都必须走到最后。 |
| **16** | **管鲍之交****故事　**春秋时期，管仲与鲍叔牙曾经一起经商。分利时，管仲常常多拿一些，鲍叔牙知道他家境贫困，从不认为他贪婪。后来两人各为其主，经历政治变故，鲍叔牙仍然向齐桓公推荐管仲，认为他的才能远胜自己。管仲后来成为齐国名相，帮助齐桓公成就霸业。**解读　**真正的知己，能够看见一个人的难处，也看得见他的长处。人与人之间最难得的信任，是不因一时得失误解对方，也不因立场变化轻易否定曾经的情谊。 |
| **17** | **高山流水****故事　**春秋时期，琴师伯牙善于弹琴，钟子期能够听懂他的琴声。伯牙弹奏时，心中想到高山，钟子期便说琴声巍峨如高山；伯牙想到流水，钟子期便说琴声浩荡如流水。钟子期去世后，伯牙认为世上再没有真正懂得自己琴声的人，于是摔琴绝弦。**解读　**人生难得一知己。很多时候，我们并不缺少交谈的人，缺少的是能够听懂内心、理解沉默的人。真正的知音，不必时时陪伴，却能让人感到自己的思想和情感被认真看见。 |
| **18** | **举案齐眉****故事　**东汉时期，梁鸿与孟光结为夫妻。孟光每次给梁鸿送饭，都将托盘举到与眉毛齐平的位置，以示尊重。两人生活清贫，却相互敬重、彼此扶持，后来成为传统文化中夫妻相敬如宾的典范。**解读　**一段长久的关系，需要尊重，也需要体谅。生活不可能永远风平浪静，真正能够走得长远的伴侣，往往懂得珍惜对方的付出，也愿意在平凡日子里认真对待彼此。 |
| **19** | **东床坦腹****故事　**东晋时期，太尉郗鉴想为女儿挑选女婿，派人到王家观察子弟。王家子弟听说郗家来选婿，纷纷表现得拘谨，唯有王羲之坦然躺在东边的床上，袒露腹部，神态自若。郗鉴听后十分欣赏，最终选中了王羲之。**解读　**真正的气度，常常体现在不刻意表现自己。越是急于讨好别人，越容易失去自然；越能保持从容，越容易显露真实的性情。一个人的魅力，有时恰恰来自不慌不忙。 |
| **20** | **梁上君子****故事　**东汉时期，陈寔在家中发现一名小偷藏在房梁上。他没有大声呵斥，而是召集子孙，告诫他们做人要勤勉自立，不要沦为不劳而获的人。随后，他对梁上的人说，君子应该反省自己。小偷听后羞愧地下来，向陈寔认错。陈寔没有惩罚他，还送给他一些布匹。**解读　**面对犯错的人，严厉惩戒并非唯一办法。有时，一句有分寸的劝告，反而能让人真正意识到自己的问题。宽厚与原则并不冲突，关键在于能否看清事情的轻重。 |
**叁**
**谋略智慧**
_看清局势，才能找到破局之道_
──── ◆ ────
| **21** | **围魏救赵****故事　**战国时期，魏国进攻赵国，赵国向齐国求援。齐将田忌准备直接赶往赵国，军师孙膑却建议进攻魏国都城大梁，迫使魏军回师。魏军果然撤离赵国，齐军趁其疲惫，在桂陵设伏，大败魏军。**解读　**面对困局，未必一定要沿着对方设定的路线行动。真正高明的谋略，是找到问题的关键环节，改变局势，让对手不得不调整原来的计划。解决问题，有时需要换一个方向。 |
| **22** | **田忌赛马****故事　**齐国贵族田忌喜欢赛马，却总是输给齐威王。孙膑观察两人的马匹后，发现双方马匹实力相近，只是各等级之间存在差距。于是他建议田忌调整出场顺序，用自己的下等马对阵对方上等马，再以自己的上等马和中等马对阵对方的中等马、下等马。最终田忌以两胜一负获胜。**解读　**同样的资源，使用方式不同，结果可能完全不同。人生中有些竞争，拼的并非单纯的实力大小，还包括策略、顺序和对自身条件的判断。懂得扬长避短，才能让有限的优势发挥最大作用。 |
| **23** | **鸿门宴****故事　**秦朝灭亡后，刘邦率先进入关中。项羽得知后，率军驻扎鸿门，准备讨伐刘邦。宴席之上，项羽谋士范增多次示意项羽动手，项庄也借舞剑之名伺机刺杀刘邦。幸而项伯出面遮护，张良、樊哙等人从旁周旋，刘邦最终借机脱身。**解读　**鸿门宴是楚汉相争的重要转折之一。一个人身处复杂局势，既要看清眼前的利益，也要看见潜藏的危险。犹豫、轻敌和判断失误，往往会让本来占据优势的人错失机会。 |
| **24** | **暗度陈仓****故事　**秦末汉初，刘邦被封为汉王，前往汉中。为迷惑项羽，他命人烧毁通往汉中的栈道，表示无意东进。随后，刘邦采纳韩信建议，明修栈道，暗中从陈仓出兵，迅速夺取关中。后来“暗度陈仓”便成为声东击西、出其不意的代名词。**解读　**面对强大的对手，正面硬拼未必是最好的选择。懂得隐藏真实意图，寻找对方疏忽的地方，才能在复杂局面中争取主动。真正的策略，往往藏在不显眼的行动里。 |

| **81** | **杯酒释兵权****故事　**北宋建立后，宋太祖赵匡胤担心手握兵权的将领可能威胁皇权。一次宴会上，他向石守信等将领表达自己的忧虑，随后以优厚待遇劝他们交出兵权，回家安享富贵。此事后来被称为“杯酒释兵权”。**解读　**权力交接往往伴随着复杂的人际关系。赵匡胤没有采取直接清洗的方式，而是通过利益安排缓和矛盾。这个故事也提醒人们，处理复杂关系时，既要考虑眼前局面，也要考虑各方的实际需求。 |
| **82** | **惊弓之鸟****故事　**战国时期，魏国名将更羸与魏王外出，看到天空中飞过一只大雁。更羸只拉弓作势，弓弦一响，大雁便应声坠落。原来，这只大雁曾经受过伤，听到弓弦声便惊慌失措，旧伤发作，无法继续飞行。后人以“惊弓之鸟”形容受过惊吓、容易恐惧的人。**解读　**经历过伤害的人，往往会对相似的情境格外敏感。人与人相处，要懂得理解别人的恐惧，也要学会处理自己的心理阴影。过去的经历不应永远决定未来，但它确实需要时间来修复。 |
| **83** | **百步穿杨****故事　**春秋时期，楚国将领养由基以善射闻名。传说他能够在百步之外射中杨柳叶，而且百发百中。楚国将领潘党曾与他比试射箭，养由基展示了惊人的箭术，令众人叹服。后世以“百步穿杨”形容箭法高超，也比喻本领精湛。**解读　**真正的高手，往往在别人看不到的地方下过苦功。所谓天赋，离不开长期训练；所谓精准，也来自无数次重复。一个人想在某个领域有所成就，必须愿意把基本功练到极致。 |
| **84** | **讳疾忌医****故事　**春秋时期，扁鹊拜见蔡桓公，发现他身体有病，便提醒他及时治疗。蔡桓公不以为然，认为自己没有病。此后扁鹊几次提醒，蔡桓公始终不肯接受。等到病情严重时，扁鹊判断已经无力回天，最终蔡桓公病逝。**解读　**人最难面对的，有时正是自身的问题。发现错误并不可怕，可怕的是因为害怕承认，就拒绝听取任何意见。一个人只有敢于正视问题，才有机会及时改变。 |
| **85** | **请君入瓮****故事　**唐朝时期，武则天执政期间，酷吏周兴与来俊臣都以严刑逼供闻名。后来有人告发周兴谋反，来俊臣奉命审问。来俊臣故意请教周兴如何对付不肯认罪的人，周兴说，可以烧热大瓮，把犯人放进去。来俊臣便命人搬来大瓮，告诉周兴若不招供，就将他放进去。周兴只得认罪。**解读　**一个人长期用残酷手段对待别人，最终也可能遭遇同样的命运。权力和手段若失去约束，便会成为伤害他人的工具，也可能反噬自己。 |
| **86** | **口蜜腹剑****故事　**唐玄宗时期，宰相李林甫善于揣摩皇帝心意，表面上对人温和友善，暗地里却常常排挤、陷害政敌。史书评价他“口有蜜，腹有剑”，意思是嘴上说着好听的话，心里却藏着锋利的刀剑。后来“口蜜腹剑”便用来形容表面和善、内心阴险的人。**解读　**判断一个人，不能只看他说话是否动听。真正值得信任的关系，需要时间检验，也需要观察对方在利益面前的选择。言语可以伪装，长期行为却很难一直掩饰。 |
| **87** | **马革裹尸****故事　**东汉名将马援年少时便立志报国，后来长期征战边疆。他曾表示，大丈夫应当战死沙场，用马皮包裹尸体送回故乡。马援一生征战，最终病逝于军中。后人以“马革裹尸”形容将士战死沙场、为国尽忠的壮志。**解读　**真正的担当，意味着愿意承担责任，也意味着明白选择背后的代价。一个人若只想获得荣誉，却不愿承担责任，便很难真正成就一番事业。 |
| **88** | **老当益壮****故事　**东汉名将马援年老之后，仍然希望为国家效力。有人认为他年纪已大，不宜再出征，马援却表示，自己虽然年长，志向仍然坚定。后来他再次领兵出征，继续为东汉立下功劳。后人用“老当益壮”形容年纪虽大，志气和精神依然旺盛。**解读　**年龄会改变身体，却不必决定一个人的精神状态。只要心中仍有目标，愿意学习、行动和承担责任，人生就仍然有新的可能。真正的衰老，有时从放弃追求开始。 |
| **89** | **草木皆兵****故事　**东晋时期，前秦皇帝苻坚率领大军进攻东晋，在淝水一带与晋军对峙。前秦军队人数众多，却因战局不利而陷入混乱。苻坚登高远望，看到八公山上的草木，以为都是晋军士兵，心中十分恐惧。后来“草木皆兵”便用来形容人在极度惊恐时疑神疑鬼。**解读　**恐惧会影响判断，也会放大危险。越是在压力巨大的时候，越要保持冷静。很多时候，真正让人陷入困境的，不只是外部威胁，还有自己失去理智后的错误判断。 |
| **90** | **塞翁失马****故事　**古代有位老人住在边塞，家中的马跑丢了，邻居纷纷前来安慰。老人却说，丢马未必是坏事。后来马带着一匹好马回家，邻居又来道贺，老人仍说未必是好事。果然，儿子骑马摔断了腿。后来征兵，儿子因伤免于出征，保住性命。这个故事被称为“塞翁失马，焉知非福”。**解读　**人生的得失，很少能在当下看得清清楚楚。眼前的好事，未必永远带来好结果；眼前的坏事，也可能成为新的转机。面对变化，少一些急于下结论，多一些耐心和从容。 |

| **91** | **朝三暮四****故事　**《庄子》中记载，养猴人给猴子分橡实，先说早上三颗、晚上四颗，猴子们十分生气；他改口说早上四颗、晚上三颗，猴子们便高兴起来。实际上，橡实总数并没有变化，只是说法不同。后来“朝三暮四”常用来形容反复无常，也揭示了人容易被表面变化影响的心理。**解读　**人有时会被表达方式左右，忽略事情本身。面对选择，要学会看清实际内容，不要只被表象和情绪牵着走。真正的判断力，来自独立思考。 |
| **92** | **望洋兴叹****故事　**《庄子·秋水》中，黄河之神河伯看到秋季洪水暴涨，觉得天下壮阔尽在自己眼前。后来他来到北海，发现海水无边无际，才意识到自己原先的见识十分有限。面对浩瀚的大海，河伯只能感叹自己的渺小。后人以“望洋兴叹”形容面对宏大事物时感到无能为力。**解读　**一个人真正开始成长，往往从意识到自身局限开始。见识越广，越能发现世界远比想象复杂。保持谦逊，愿意不断学习，才能走出狭小的认知范围。 |
| **93** | **邯郸学步****故事　**《庄子》中记载，燕国寿陵有个年轻人，听说赵国邯郸的人走路姿态优美，便专程前往学习。他刻意模仿当地人的步态，结果没有学会，反而忘记了自己原来的走法，只能爬着回家。后来“邯郸学步”用来形容盲目模仿别人，最终失去自身特点。**解读　**学习别人值得肯定，但不能失去独立判断。别人的经验可以借鉴，别人的道路却未必适合自己。一个人若只顾模仿外在形式，反而容易丢掉最适合自己的东西。 |
| **94** | **庖丁解牛****故事　**《庄子·养生主》中，庖丁为梁惠王宰牛，动作娴熟，刀锋游走于筋骨缝隙之间，仿佛从未遇到阻碍。梁惠王十分惊叹，庖丁解释说，自己刚开始宰牛时，看到的只是整头牛；多年之后，已经能够顺着牛的结构下刀，避开筋骨交错之处。**解读　**真正的熟练，来自长期观察与实践。一个人做事做到一定程度，便能逐渐掌握规律，不再依靠蛮力。面对复杂问题，懂得顺势而为，往往比一味用力更有效。 |
| **95** | **庄周梦蝶****故事　**《庄子·齐物论》中，庄子讲述自己曾梦见化作一只蝴蝶，翩翩飞舞，自由自在，完全不知道自己是庄周。醒来之后，他又疑惑：究竟是庄周梦见自己变成蝴蝶，还是蝴蝶梦见自己变成庄周？这个故事被称为“庄周梦蝶”。**解读　**庄周梦蝶引发了人们对真实、自我和世界的思考。我们习以为常的认知，未必就是世界的全部。保持开放的心态，承认自己的认识可能存在局限，才能拥有更宽阔的精神空间。 |
| **96** | **胸有成竹****故事　**北宋画家文同擅长画竹。他长期观察竹子的生长形态，对竹子的枝叶、疏密和姿态了然于心。每次作画之前，心中已经形成完整的竹子形象，因此落笔时十分从容。苏轼曾称赞他的画竹之法，后人便以“胸有成竹”形容做事之前已有成熟计划。**解读　**从容的背后，是充分准备。真正的自信，不是盲目相信自己能够成功，而是因为已经认真思考、反复练习，知道接下来应该怎样做。 |
| **97** | **画龙点睛****故事　**南朝画家张僧繇擅长绘画。传说他在金陵安乐寺墙壁上画了四条龙，却没有点上眼睛。有人问他为什么，他说一旦点睛，龙便会飞走。众人不信，要求他点睛。张僧繇点了其中两条龙的眼睛，顷刻间雷电大作，龙破壁飞去。**解读　**画龙点睛后来用来形容在关键处稍加点拨，使整体更加生动传神。做事有时不在于增加多少内容，而在于能否抓住关键。一个恰到好处的细节，可能决定整体的效果。 |
| **98** | **入木三分****故事　**东晋书法家王羲之以书法闻名。传说他在木板上写字，工匠雕刻时发现，墨迹竟然渗入木板深处，仿佛进入木头三分。后人以“入木三分”形容书法笔力强劲，也用来比喻分析问题深刻透彻。**解读　**真正有力量的表达，往往能够触及事物的本质。看问题不能只停留在表面，写文章也不能只追求辞藻华丽。只有经过深入观察和思考，才能说出真正有分量的话。 |
| **99** | **程门立雪****故事　**北宋时期，杨时与游酢前往拜访理学家程颐。两人到达时，程颐正在闭目养神，他们不愿打扰，便站在门外等候。那时正值冬日，雪越下越大，等程颐醒来时，门外的积雪已经很深。后人以“程门立雪”形容尊师重道、求学心诚。**解读　**求学需要敬畏，也需要耐心。真正的学习，不只是获取知识，还包括对知识和师长的尊重。一个人越是愿意放低姿态，越有可能从别人身上学到真正有价值的东西。 |
| **100** | **断齑画粥****故事　**北宋名臣范仲淹幼年家境贫寒，在应天府书院求学时，生活十分艰苦。他常常将粥煮好，凝固后切成四块，早晚各吃两块，再配上一点腌菜。这样的生活持续多年，他却始终勤奋读书，最终成为一代名臣和文学家。**解读　**一个人的起点并不决定终点，真正决定人生走向的，是面对困境时的态度和行动。艰苦的环境可以磨炼意志，也能让人更加懂得珍惜机会。那些年轻时吃过的苦，若能转化为能力与担当，便会成为人生最宝贵的财富。 |
**结　语**
读完这一百个历史典故，会发现历史离我们的生活并不遥远。
许衡面对一棵梨树，守住了内心的底线；杨震面对深夜送来的黄金，拒绝了无人知晓的诱惑；苏武在漫长的流放岁月里，没有丢掉自己的气节；廉颇与蔺相如放下个人恩怨，成就了将相和的佳话；韩信忍受胯下之辱，最终在历史上留下自己的名字。
也有人因为贪婪而走向覆灭，因为傲慢而错失良机，因为听不进劝告而付出沉重代价。那些曾经发生在宫廷、战场、朝堂和市井里的故事，直到今天，仍然能让我们看见熟悉的人性。
人生几十年，难免遇到诱惑、误解、挫折和选择。有人在顺境中迷失，有人在困境中坚持；有人因一时冲动毁掉多年积累，也有人凭借一次清醒的决定改变人生方向。
读历史典故，读到最后，读的其实是人心。
愿我们记得古人的坚守，也看清古人的教训；遇到诱惑时守住底线，面对困境时保有勇气，与人相处时懂得分寸，面对得失时多一份清醒。
一百个故事，写尽世间百态；一百种智慧，留给每一个正在认真生活的人。
