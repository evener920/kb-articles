# QuickShot：悬停即截、标注美化一条龙的本地截图工具

QuickShot 是一款本地优先的截图工具，覆盖 macOS 与 Windows。把指针移到窗口上、点一下就截下那一扇窗，接着标注、美化、拼接都在同一个编辑器里完成，而所有内容都留在你自己的电脑上。用一条快捷键即可触发，并内置十种标注工具与一键演示级美化。
截图这件事，从"截下来"到"能拿去用"之间往往还隔着标注、去私密信息、调背景、拼长图好几步，很多人要在不同软件间倒腾。QuickShot 把这一串动作收进一个本地应用：你不必先把屏幕冻结，指针移到哪扇窗，哪扇窗就被柔和的光谱描边圈出，点一下只截它，遮挡的窗口自动排除；截完编辑器立刻弹出，标注、美化、拼接一气呵成。
更关键的是它把"截"和"用"之间的那段手工劳动接管了。系统自带的截图能快速截取，却几乎不做标注与美化；另一些工具要么把图片传上云、要么要你按月订阅。QuickShot 反过来：所有处理都在本地完成，截完就能直接标注去敏、调成演示级背景、拼成对比图，最后复制到剪贴板或存盘，整个过程不离开你的机器，也不用注册任何账号。
这套取舍特别适合经常要「截了马上发」的人：写 bug 反馈、做教程、写文档、在群里解释一个界面问题。过去你截完要开另一款工具打码、加箭头、再导出，链路一长就容易随手把图丢进某个云盘或聊天工具；QuickShot 把这些步骤压进同一次「按键到复制」之间，截、标、美、发都在本地一气呵成，既不打断思路，也不必担心截图里临时的 token 或内部地址被传到不知名服务器。对一个重视隐私、又讨厌在工具间反复横跳的人来说，这种紧凑尤其舒服。
**核心能力**
**•**悬停即截：对象是取景。默认行为是屏幕保持原样不动，指针下的窗口被光谱描边点亮，单击截该窗、拖拽截区域、点桌面截全屏；macOS 上单独截一扇窗，重叠窗口自动排除，圆角保持透明。开关上，macOS 还可在托盘菜单切到系统原生十字光标（含空格截单窗）。
**•**十种标注：对象是编辑器里的标注层。默认行为是每个工具占一个快捷键——选择、矩形、椭圆、箭头、直线、钢笔、高亮、文字、编号步骤、消隐（像素化或模糊），且画完仍可改：移动、缩放、换色、重复或删除。开关上，Smart Redact（Mod+Shift+M）会读取截图上本机文字，一步盖住用户名主机名、邮箱、IP、MAC 与常见密钥，一键撤销全部。
**•**一键美化：对象是导出样式。默认行为是提供网格渐变、墙纸、纯色、模糊副本或透明背景，外加经典卡片、磨砂玻璃、macOS 深/浅与浏览器窗口等窗框；内边距、圆角、分层柔影与社交比例（1:1、4:3、16:9、3:4、9:16）可调，还能加自动选色的签名水印。把美化关掉即可导出带标注的纯截图。
**•**拼接与钉浮：对象是多图与浮窗。默认行为是 Mod+Shift+A 再截一张接上当前图，或粘贴、拖入图片，按竖排、横排或网格排布，间距与对齐可调；还能把截图钉成始终置顶的浮窗（可调透明度与点击穿透），或用本机 OCR 抽出文字。
**•**隐私与轻量：对象是你的数据。默认行为是截图与其中文字从不出本机，没有账号也没有云；自 1.2.0 起每启动只发一条匿名统计（随机安装 ID、版本、系统、CPU），可在 settings.json 把 usageStats 设为 false 关闭。开关上，渲染进程采用上下文隔离、无 Node 访问、白名单 IPC，截屏权限只在你需要时申请，开发者构建则完全不发统计。

整条链路都围着一条全局快捷键展开：截完进编辑器，V/R/O/A/L/P/H/T/N/M 切换十种标注，Mod+Shift+M 一键去敏，Mod+Shift+A 拼接，Mod+Shift+P 钉浮，Mod+Shift+T 抽文字，Mod+Enter 复制并关闭。换句话说，从截到发，手指几乎不离开键盘；编辑器窗口还被常驻后台"保温"，所以你一选完区域它就立刻弹出，没有等待感。
更顺手的是它能把常用的一套美化「钉」成默认。你在样式面板里调好的背景、窗框、圆角与签名，可以存为默认样式，之后每次新截图都自动套用，不必重复点选；想临时换风格也能随时在面板里改。对要批量出图的人来说，这等于把「演示级外观」变成出厂设置，而不是每次重做一遍。再配合钉浮窗——把一张参考图或报错图始终压在最上层、还能调透明度与点击穿透——你在比对两个界面、照着抄一个布局时，连切窗口都省了。
**环境与安装**
QuickShot 支持 macOS 12 以上与 Windows 10/11，提供 Apple 芯片与 Intel 的通用构建，以及 Windows 64 位安装包。macOS 版本未做公证，首次打开被拦时，可在终端执行放行命令后重开，或在系统设置里点"仍要打开"。Windows 版的文字提取使用系统设置里已安装的 OCR 语言包。

**实操主路径**
最常用的一条线是：在任何界面按下 Mod+Shift+X（macOS 为 ⌘⇧X，Windows 为 Ctrl+Shift+X），屏幕不冻结，移到目标窗口单击即可截下它，编辑器随即打开。接着按需标注：按 V/R/O/A/L/P/H/T/N/M 切换选择、矩形、椭圆、箭头、直线、钢笔、高亮、文字、编号、消隐；要去掉敏感信息就按 Mod+Shift+M 让 Smart Redact 一键盖住。满意后 Mod+Enter 复制并关闭，或 Mod+S 存到下载目录。
举一个完整例子：你在调一个界面，想给同事看某处报错。按 ⌘⇧X，移到那个窗口单击，错位的弹窗不会混进来；进编辑器后按 R 拖个矩形框住报错区，按 A 拉箭头指向关键行，按 T 写一句说明，再按 Mod+Shift+M 让 Smart Redact 把截图里暴露的用户名和路径盖掉；确认无误后 Mod+Enter 直接进剪贴板，切到聊天窗口一贴了事。全程键盘操作，截图从没离开过本机。把这条线练熟，你几乎不会再为了「发张图说明问题」而离开当前上下文去开别的软件。
**另外两条值得跟做的路径**
其一，拼接长图或对比图。据官方文档，在编辑器里按 Mod+Shift+A 再截一张，或粘贴/拖入图片，即可把它拼到当前图；可在竖排、横排、网格之间切换，并调整间距与对齐，标注会跟着它所在的截图一起移动，整张拼图都能再美化、导出、钉浮或抽文字。
其二，本机文字提取与隐私。导出或钉浮之外，还能用本机 OCR 从截图里抽文字（macOS 走 Apple Vision，Windows 走系统 OCR），全程不联网；截图与其中文字从不出本机，没有账号也没有云，自 1.2.0 起每次启动只发一条匿名统计（随机安装 ID、版本、系统与 CPU），可在 settings.json 里把 usageStats 设为 false 关闭。
**关键实现**
QuickShot 基于 Electron 39 与 React 18，用 TypeScript 5 编写；主进程负责托盘、取景、窗口与 IPC，渲染进程跑编辑器与取景层，OCR 在 macOS 上由 Apple Vision 的原生助手完成，Windows 上通过 PowerShell 调 Windows.Media.Ocr。编辑器逻辑是纯函数式的标注、几何、布局与渲染，和 UI 解耦，所以标注对象可被反复选中、改属性、撤销重做而不破坏底层。在 macOS 上，取景由一个常驻的 ScreenCaptureKit 助手完成，窗口检测则由独立的原生助手负责，因此"悬停圈窗"能做到既实时又不卡界面。
选择 Electron 与 React 而不是纯原生套件，换来的是 macOS 与 Windows 一套代码、迭代更快，代价是包体比纯原生略大一些；对一款「常驻后台、随叫随到」的小工具来说，这个取舍是划算的。渲染进程被严格隔离、只走白名单 IPC，意味着即便将来接入某个新功能，截屏权限与文件系统访问仍被收在主进程这一侧，攻击面相对可控。理解这一点，你在评估它是否进公司环境时，会更容易判断它到底碰了什么、没碰什么。

**边界与代价**
QuickShot 的源代码以 GNU GPL v3.0 发布，第三方代码保留各自许可证；但随包附带的墙纸图片是第三方资产，许可证不覆盖它们，再分发需自行确认授权.
平台差异上，macOS 未公证，首次启动需手动放行；滚动截图依赖开发期环境变量与 fixture，普通用户走常规取景即可。隐私取舍上，它刻意不做云同步，因此跨设备同步要靠你自己的方式。对只想"截了就走"的人来说，这种本地优先反而最省心。
最适合把截图当作日常沟通语言的人——开发者、设计师、客服，以及写文档与教程的创作者；对需要团队共享标注模板、或强依赖云同步图库的场景，它的本地优先反而会显得「太轻」。此外 macOS 未公证意味着在企业管控严格的机器上，可能要先过一道放行流程，这点在大面积部署前要先心里有数。许可证是 GPL-3.0，第三方代码保留各自许可；随包附带的墙纸是第三方素材，再分发时需自行确认授权，这点和代码许可证要分开看待。
**可以怎么开始**
从官方仓库的 Releases 或项目主页取对应平台的安装包，macOS 拖进 应用程序、Windows 跑安装向导即可，之后它就常驻菜单栏（或通知区）。想改全局快捷键或给滚动截图单独设键，在菜单栏菜单的 设置 里调整。把第一次截图交给悬停取景，是感受它"轻"的最快方式。
想从源码看它怎么实现、或自己改一版，官方给出的是标准前端工作流：需要 Node.js 20.19 以上或 22.12 以上，克隆仓库后 npm install 再 npm run dev 即可；另有 npm run dev:ui 可在不带 Electron 与截屏权限的情况下，用 HTML fixture 单独打磨编辑器界面，迭代最快。仓库按职责分层，electron/ 管主进程与取景，src/ 里是纯编辑器逻辑与界面组件，native/ 下是 macOS 的 OCR 与窗口检测助手，读起来不费劲，想加一种标注或一种窗框样式也都是改同一处逻辑。
