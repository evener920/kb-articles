# 纯本地、开源的 AI 网文写作桌面软件，支持小说创作、AI 辅助写作、BYOK 与自定义提示词

> **易创（easy-writing）是一款纯本地、开源的 AI 网文写作桌面软件，它由长期线上运营的写作平台客户端改造而来，编辑器、自动保存、章节管理都经过真实网文作者的日常使用打磨。
> **
软件提供写作台、卷章管理、码字统计、参考资料五件套等基础写作功能，并支持 BYOK **（自备密钥）**方式接入 DeepSeek、通义千问、Ollama 等 AI 模型,实现润色、续写、一键建书等辅助创作。
适合起点、番茄、七猫、晋江等平台的网文创作者，也适合希望完全自主掌握文稿的写作者。
![](assets/纯本地、开源的 AI 网文写作桌面软件，支持小说创作、AI 辅助写作、BYOK 与自定义提示词-1.jpg)
#### 要点
- **本地优先**：作品、设定、码字记录全部存本机（桌面版为 SQLite 数据库文件），无需注册登录，基础写作功能可离线使用，支持自动备份与整本导出。
- **AI 采用 BYOK 模式**：自备 API Key，支持 DeepSeek、通义千问、智谱、Kimi、OpenAI 等服务商及 OpenAI 兼容接口，也支持 Ollama、LM Studio 等本地部署模型；Key 仅存本机，请求从用户电脑直连服务商。
- **提示词全开放**：所有 AI 提示词为本机 md 文件，可在界面可视化编辑或直接改文件，每个场景的采样温度均可调。
- **写作功能完整**：TipTap 富文本编辑器、卷/章目录树、全书搜索、160ms 自动落盘、每章自动保存历史版本、敏感词检测、专注模式与“自爆挑战”。
- **参考资料五件套**：大纲、角色（含关系图画布）、设定、时间线、故事线（思维导图画布）。
- **AI 工作流一键建书**：灵感 → 大纲 → 设定 → 建书 → 逐章自动生文，断点可续；另有竞品拆书（黄金三章深析）、续写补全、划词润色、取名器等功能。
- **榜单风向（仅桌面版）**：内置爬虫抓取起点、番茄、七猫等 80+ 源的排行榜，数据只存本机，支持趋势分析、CSV 导出与 AI 解读。
#### 安装与使用
- **普通用户**：从 Releases 发行版页面 下载安装包——macOS 下载 .dmg，Windows 下载 .exe。装好后「新建作品」即可直接开写，写作功能无需任何配置。
- **启用 AI**：侧栏「模型管理」→ 选服务商预设 → 填入自己的 API Key → 测试连接 → 保存并设为默认模型；提示词可在「提示词管理」中按场景修改。
- **开发者本地运行**：`pnpm install` 后 `pnpm dev` 启动浏览器开发模式（端口 6789）；桌面端打包需先安装 Rust，再通过 Tauri 2 执行 `pnpm tauri build`。
