"究天人之际，通古今之变，成一家之言。"
两千年前，司马迁用毕生心血写就了《史记》。两千年后，一群程序员和文史爱好者用 AI 和数据技术，把它变成了一部**可交互的数字知识图谱**。
最让人感动的是——**这个项目是开源的**。
#### 什么是 shiji-kb
shiji-kb 是一个 AI 驱动的《史记》知识库项目，基于 baojie/shiji-kb。它不只是把《史记》的文本放到网上，而是：
1. **结构化实体提取**：从原文中自动识别和提取人物、地名、官职等实体
1. **关系挖掘**：分析实体之间的关联
1. **知识图谱构建**：把关系和实体可视化
1. **全文索引**：130 篇可全文搜索
#### 开源意味着什么
**完全免费**
不需要付费、不需要注册、不需要下载 App。网页打开就能用。
**数据可访问**
所有 581 MB 的知识库数据都在公开的 GitHub 仓库中。你可以下载全部数据，用于自己的研究或项目。
**社区驱动**
项目在 GitHub 上由社区维护。如果你发现数据不准确、缺少某个实体——可以提 Issue 或 PR，改进会惠及所有使用者。
**可复制**
整个站点是纯静态 HTML，没有后端，没有数据库。任何人都可以自行部署。
#### 为什么这很重要
古籍数字化的挑战不在于"把文字放到网上"——那只是第一步。
真正的挑战在于：
- **打通**：让不同篇章中同一个人的信息互相关联
- **可查**：让读者能快速找到自己想看的内容
- **可理解**：帮读者理解陌生的名词和背景
shiji-kb 在这三个方面都做得很好——而且因为它是开源的，这些工作成果可以被所有人复用。
