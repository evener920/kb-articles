**Riff 是一款免费开源、零广告零遥测的桌面音乐播放器，把 YouTube Music、YouTube、SoundCloud 的流媒体与本地无损音乐装进同一个界面，并自带均衡器、音频编辑、同步歌词等一整套音频工具箱。
**
用作者的话就是：免费、开源的桌面音乐播放器，面向 YouTube Music、SoundCloud 和本地文件。
![](assets/414feb00ed728177-1.png)
![](assets/414feb00ed728177-2.png)
**要点**
- **多平台聚合播放**：YouTube Music、YouTube、SoundCloud 流媒体直接听，无广告、不用注册账号。
- **本地无损音乐库**：支持 FLAC、WAV、MP3、OGG、M4A，自动读取标签与封面，不改动磁盘原文件。
- **歌单一键迁移**：粘贴 Spotify / Apple Music / YouTube Music / SoundCloud 公开歌单链接，自动逐曲匹配生成可编辑的本地歌单；Spotify 超 100 首的歌单也能分页导入。
- **内置音频编辑器**：无损裁剪、截取片段另存为新文件，原曲不受影响。
- **均衡器 + 实时音效**：10 段参数均衡器自带低音增强、人声清晰、电子、扁平、摇滚等预设；播放中可实时变速不变调、变调、加混响与失真。
- **离线下载管线**：流媒体可保存为 MP3 / FLAC / Opus / WAV，自动写入 ID3 标签和高清封面。
- **同步歌词与卡拉 OK**：多来源自动搜词，支持 LRC 文件、手动校时、多语言翻译和全屏歌词动画。
- **高颜值可定制**：Material Design 3 界面，主题色随当前专辑封面动态生成，内置主题编辑器和 CSS 编辑器。
- **可视化与联动**：WebGL 硬件加速频谱特效，Discord 可实时展示正在听的曲目、歌手和已播时间。
- **隐私与扩展**：零遥测、数据全部留在本地，自带插件系统可扩展功能。
- **内存占用**：播放时约 180MB，按项目标准，持续超过 600MB 才算泄漏。
**上手**
- **环境门槛**：Windows 10/11 和主流 Linux 开箱即用，Releases 页的标准安装包已内置 yt-dlp、ffmpeg，无需二次配置；macOS 为实验性支持，分 Apple Silicon / Intel 两个 dmg 版本，因二进制未签名，首次需右键“打开”确认，若提示“已损坏”，在终端执行 `xattr -cr /Applications/Riff.app`，并需自行通过 Homebrew 安装 yt-dlp 和 ffmpeg。
- **获取形态**：预构建安装包在 Releases 页，想自行编译需 Node.js 18 及以上和 npm。
- **没有官方手机版**：没有官方 Android / iOS 版，README 只列了一个社区分支链接，下载时注意甄别，不要当成官方版。
- **合规提醒**：项目自我定位为教育用途与个人媒体管理，从第三方平台解析、下载音源前，请自行确认平台服务条款与当地版权法规。
