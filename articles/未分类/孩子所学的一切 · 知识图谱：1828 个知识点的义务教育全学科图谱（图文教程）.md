**工具地址**：[1]https://hwx1.gzweidu.top/tool/os-taxonomy[2]**一句话介绍**：一张能在浏览器里漫游的义务教育全学科知识图谱（中文版）：**1828 个微主题、3896 条前置关系（含 344 条跨学科锚定）、9 大学科、覆盖 4–13 岁**，6 种粒子布局（星图 / 年轮 / 矩阵 / 球体 / 龙卷风 / 环状）；点开任一知识点，能看到它「在讲什么、为什么重要、怎么学更好、掌握证据自检清单、前置与后续」。**纯静态、零后端、零上传**，断网可用。

### 一、打开：先看开场页，再进图谱
浏览器访问上面的地址，会**自动整页打开**图谱（如果浏览器拦截了新标签页，工具页会给出一个手动按钮）。也可以从工具站首页进入：**Office / 办公 → 孩子所学的一切 · 知识图谱**（带「新」标）。
![](assets/406feb00ed7281ca-1.png)
开场页先把规模摊开讲清楚：
![](assets/406feb00ed7281ca-2.png)
- **1828 知识点**：一个知识点就是一个「微主题」，颗粒度足够小，可以逐个点亮
- **3896 前置关系**：连线有方向，回答的是「要抵达这里，必须先点亮哪些光」
- **4–13 覆盖年龄**：从说出第一个词，到理解代数
- **9 学科门类**：语文（读写素养）、数学、英语、科学、历史、信息科技、道德与法治 · 综合实践、生活与劳动、学会学习（跨学科素养）
点「进入星图」就进图谱。
### 二、六种视角看同一张图谱
同样的 1828 个知识点、3896 条关系，可以切换 **6 种粒子布局**：
- **星图**：按学科分色成簇，像一张星座图，能看出学科之间的疏密
- **年轮**：按年龄分层，一圈一圈往外长——适合看「几岁该学什么」
- **矩阵**：规整排布，适合横向对比
- **球体**：按年龄分壳，立体感强
- **龙卷风**：年龄就是高度，越往上越大
- **环状**：学科绕环、年龄绕管
![](assets/406feb00ed7281ca-3.png)
![](assets/406feb00ed7281ca-4.png)
> 连线细而淡是上游的设计：3896 条前置边会**按缩放阈值**绘制，远看是干净的星座，放大后才显出结构——想看关系，滚轮放大即可。

### 三、看一个知识点：讲解 / 评测 / 脉络
**单击任意圆点**，右侧滑出详情抽屉：
![](assets/406feb00ed7281ca-5.png)
抽屉顶部是四个标签：**类型**（如程序性 / 概念性）、**领域**、**年龄**、**连接度**；下面三个页签：
- **讲解**：这个知识点在讲什么 / 为什么重要（在哪个学科、哪个领域，依赖几个前置、能解锁几个后续）/ 怎么学更好（建议先稳稳掌握哪几个前置）
- **评测**：**掌握证据自检清单**（达到什么程度算真的会了，逐条自检）+ 前置自测（先确认前置已内化）
- **脉络**：前置与后续知识点，以及对应的课标条目（含中国课标 2022 年版）
以「10以内熟练加减」为例：它的前置是「凑十（10的组合）」「5以内熟练加减」，掌握后会解锁「20以内的加法与减法」「20以内熟练加减」——**孩子某道题不会，往往不是这一步的问题，而是前置没点亮。**
### 四、操作速查
- **拖拽**：漫游画布
- **滚轮**：缩放（放大后连线结构才看得清）
- **单击节点**：打开详情抽屉
- **双击**：聚焦到该节点
- **Esc**：取消当前选中 / 退出聚焦
- **搜索框**：输入关键词直接定位（1828 个点里靠搜比靠找快）
- **学科胶囊 + 年龄段**：只看某一学科、某一年龄段
- **顶部右侧图标**：主题切换（亮 / 暗）、图例、帮助、定位等
- **小屏**：左侧控制台可内部滚动，触屏能拖拽与双指缩放
### 五、实际能拿它做什么
- **家长查漏补缺**：顺着「前置与后续」往回看，定位真正缺的那一环
- **看清「为什么这道题不会」**：先补前置，比刷十张卷子有效
- **老师备课**：上游链、下游解锁范围、课标条目都摆在同一个抽屉里
- **给孩子定学习路径**：按年龄筛选，看这一年龄段的基石知识点，再按依赖顺序排
- **看学科之间的桥**：344 条跨学科锚定，把语文、数学、英语、科学织成互相借力的网
### 六、小技巧
- 画面太密就**双击聚焦**某个节点，或滚轮放大——连线会随缩放阈值显现
- 用**搜索框**定位，比在 1828 个点里找快得多
- 用左上角的**年龄段控件**只看某个区间
- 换**暗色主题**截图更耐看
- **断网可用**：首屏加载过一次之后，数据与字体都在本地

**Q1：要注册、要付费吗？** 不用。打开就是完整功能。
**Q2：数据会上传吗？** 不会。纯静态页面，Canvas 2D 渲染，全部数据预烘焙在本地 JSON 里，**零后端、零上传**；字体也是本地文件，全站没有外部请求。
**Q3：断网能用吗？** 首次加载完成后可以——数据和字体都在本地。
