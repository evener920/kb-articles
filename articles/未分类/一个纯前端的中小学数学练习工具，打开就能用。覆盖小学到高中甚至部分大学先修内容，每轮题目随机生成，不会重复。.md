## math-mastery
> 一个纯前端的中小学数学练习工具，不用装任何依赖，打开就能用。覆盖小学到高中甚至部分大学先修内容，每轮题目随机生成，不会重复。
> 
Github地址
**https://github.com/kenowong/math-mastery**
![](assets/407feb00ed728181-1.png)
### 功能特性
- 参数化出题：每个知识点都有专门的生成器，每次做题题干数据都不一样，答案直接由数学构造算出，不会出错
- 覆盖面广：小学10种方法（鸡兔同笼、植树问题、盈亏这些）、初中15种、高中24种，外加32个拓展专题（泰勒级数、欧拉公式、琴生不等式、傅里叶级数之类）
- 带图带解析：题目配SVG示意图，部分难点还有交互动画（单位圆旋转、函数图像变换、3σ区间阴影这些）
- 学习跟踪：按依赖关系编排学习路径，错题自动进薄弱点清单，练完返回能定位到刚才的位置
- 完全离线：单HTML文件，所有资源本地化，没网也能跑
### 怎么用
直接双击打开 `index.html` 就行。或者本地起个服务：
```
python -m http.server 8142 # 访问 http://127.0.0.1:8142/

```
项目结构很直白：`index.html` 入口、`styles.css` 样式、`js/` 下面按功能分文件（数据、出题引擎、动画、配图、主逻辑），代码89.9%是JavaScript，少量Python脚本做辅助处理。
