01 有理数的混合运算
![](assets/40cfeb00ed72815a-12.gif)
前置：绝对值 · 相反数 · 运算顺序→通向：实数运算 · 代数式求值
数与代数 · 实数
![](assets/40cfeb00ed72815a-13.png)
核心知识

运算顺序：先算乘方，再算乘除，最后算加减；同级运算从左到右；有括号先算小括号，再中括号，后大括号。
符号法则：加法：同号取相同符号、绝对值相加，异号取绝对值较大的符号、绝对值相减。乘除：同号得正、异号得负。乘方：负数的奇次幂为负、偶次幂为正。
概念辨析：−2² 读作「2 的平方的相反数」，等于 −4；(−2)² 才等于 4。同理 −2³ = −8，(−2)³ = −8。
常用技巧：凑整相加、互为相反数先结合、同分母先结合、逆用分配律提取公因数。
![](assets/40cfeb00ed72815a-14.png)
解题套路

1. 多层符号先化简：把 −(−3)、＋(−5) 统一化成单一符号后再计算。
1. 每一步只做一件事，符号单独确认一遍再往下写。
1. 含绝对值先去绝对值：先判断内部符号，再决定直接去掉还是变号。
![](assets/40cfeb00ed72815a-15.png)
易错警示

- ✕ −2² 误算成 4（负号在括号外，平方后还要变相反数）。
- ✕ 减法转加法时，只变运算符号，忘记同时改变后面数的性质符号。
- ✕ 用分配律时漏乘括号内的某一项，尤其是「−」后面的项。
![](assets/40cfeb00ed72815a-16.png)
典型例题

【例】计算：−2² + (−2)³ + |−3| × (−2) ÷ 6
【解】原式 = −4 + (−8) + 3 × (−2) ÷ 6 = −4 − 8 + (−6) ÷ 6 = −12 + (−1) = −13。【关键：−2² = −4，(−2)³ = −8；|−3| = 3】

02 因式分解
![](assets/40cfeb00ed72815a-17.gif)
前置：整式乘法 · 乘法公式→通向：解一元二次方程 · 分式约分
数与代数 · 代数式
![](assets/40cfeb00ed72815a-18.png)
核心知识

定义与方向：把一个多项式化成几个整式的积，与整式乘法互为逆变形（和差化积）。
方法顺序：一提：提公因式；二套：公式法（平方差 a²−b²=(a+b)(a−b)，完全平方 a²±2ab+b²=(a±b)²）；三十字：x²+(p+q)x+pq=(x+p)(x+q)。
分解要求：必须分解到每个因式都不能再分解为止，结果常用「×」连接写在括号外系数之后。
检验方法：把结果乘回去，看是否还原为原多项式。
![](assets/40cfeb00ed72815a-19.png)
解题套路

1. 拿到式子先看有没有公因式，有则先提；提完后首项为正、符号统一。
1. 二项式想平方差，三项式想完全平方或十字相乘。
1. 高次先降次：x³−4x = x(x²−4) = x(x+2)(x−2)。
1. 提公因式带负号时，括号内每一项都要变号。
![](assets/40cfeb00ed72815a-20.png)
易错警示

- ✕ 分解不彻底：如 x⁴−1 只分解到 (x²−1)(x²+1) 就停，还应继续分解 x²−1。
- ✕ 提公因式 −x 后括号内忘记变号。
- ✕ 与整式乘法方向弄反：分解结果是「积」，不是展开的「和差」。

典型例题

【例】分解因式：4x³ − 4x² + x
【解】原式 = x(4x² − 4x + 1) = x(2x − 1)²。【先提公因式 x，剩下的三项恰好是完全平方式：4x²−4x+1 = (2x−1)²】

03 分式化简与求值

前置：因式分解 · 分式基本性质→通向：分式方程 · 代数最值
数与代数 · 代数式

核心知识

基本性质：分子、分母同乘（除以）一个不为 0 的整式，分式的值不变——这是约分与通分的依据。
化简顺序：分子分母先因式分解 → 除法变乘法（乘倒数）→ 约分 → 加减先通分。
结果要求：必须化成最简分式或整式（分子分母没有公因式）。
求值前提：代入的字母取值必须使原分式及化简过程中所有分母都不为 0。

解题套路

1. 加减看分母：同分母直接把分子加减；异分母先因式分解找最简公分母再通分。
1. 除法一定先「颠倒相乘」再约分，不能直接约。
1. 求值时选使计算简单的数代入（但禁用值不能取），并把代入过程写出来。

易错警示

- ✕ 除以一个分式忘记「变为乘它的倒数」。
- ✕ 结果没有化到最简（分子分母还有公因式）。
- ✕ 代入的值恰好使原分母为 0，代入无效。

典型例题

【例】先化简，再求值：(1 − 1/(x−1)) ÷ (x²−x)/(x²−2x+1)，其中 x = 3。
【解】原式 = [(x−2)/(x−1)] ÷ [x(x−1)/(x−1)²] = [(x−2)/(x−1)] × [(x−1)/x] = (x−2)/x。当 x = 3 时，原式 = (3−2)/3 = 1/3。【第一步先把 1 − 1/(x−1) 通分化简，再把除法的分子分母各自因式分解】

04 分式方程

前置：整式方程 · 最简公分母→通向：工程 · 行程 · 销售应用题
数与代数 · 方程与不等式

核心知识

解法三步：① 去分母（两边同乘最简公分母）化为整式方程；② 解整式方程；③ 验根（把根代入最简公分母）。
增根来源：去分母时两边乘了可能为 0 的式子，解的范围被扩大，产生增根。
验根双检：检验是否为增根；应用题还要检验是否符合实际意义（时间、人数非负等）。
常见模型：工程问题（工作总量设为 1）、行程问题（v = s ÷ t）、销售问题（利润率、打折）。

解题套路

1. 先找最简公分母：各分母因式分解后，取「系数最小公倍数 × 所有因式的最高次幂」。
1. 解出根后立即验根，把「验」的过程写进解答，不写要扣分。
1. 应用题解出根后做双检：是增根要舍去；不合实际（负数、超过总量）也要舍去。

易错警示

- ✕ 解完整式方程直接下结论，忘记验根（最常见失分点）。
- ✕ 把增根也写进答案。
- ✕ 去分母时，不含分母的项（常数项）漏乘公分母。

典型例题

【例】解方程：x/(x−3) − 2 = 3/(x−3)
【解】两边同乘 (x−3)：x − 2(x−3) = 3，即 x − 2x + 6 = 3，解得 x = 3。检验：当 x = 3 时，最简公分母 x−3 = 0，∴ x = 3 是增根。∴ 原方程无解。【本题专门演示「解完必须验根」】

05 一元一次不等式（组）

前置：等式性质 · 数轴→通向：方案设计 · 函数自变量范围
数与代数 · 方程与不等式

核心知识

解法：与解方程完全相同，唯一区别：两边同乘（除以）同一个负数时，不等号方向必须改变。
解集口诀：同大取大，同小取小，大小小大中间找，大大小小无处找（无解）。
数轴表示：向右为大于、向左为小于；≥、≤ 画实心点，>、< 画空心圈。
应用方向：方案设计（设未知数 → 列不等式 → 取整数解 → 比较费用）。

解题套路

1. 去分母、去括号时按解方程的流程走，只在「乘除负数」这一步多检查一次变号。
1. 解不等式组先分别解出每个不等式，再在数轴上取公共部分。
1. 方案设计题：先解出 x 的范围，再取整数解，逐个代入验证，选最优方案。

易错警示

- ✕ 两边乘除负数忘记变号（本专题第一高频错误）。
- ✕ 「大大小小」误写成有解。
- ✕ 去分母时漏乘不含分母的项。

典型例题

【例】解不等式组：2x + 1 > −1 且 (x + 1)/2 > x − 1，并写出它的整数解。
【解】由 2x + 1 > −1 得 x > −1；由 (x+1)/2 > x−1 得 x + 1 > 2x − 2，即 x < 3。∴ 不等式组的解集为 −1 < x < 3，整数解为 x = 0，1，2。【两个解集在数轴上取公共部分；应用题取整数解时要逐一检验】

06 二元一次方程组

前置：一元一次方程→通向：一次函数交点 · 三元一次方程组
数与代数 · 方程与不等式

核心知识

核心思想：消元——把两个未知数转化成一个未知数。
代入消元：由一个方程解出 y = ax + b（或 x = …），代入另一个方程。
加减消元：两方程两边分别相加（减），消去系数相同（相反）的未知数；系数不相同时先乘倍数调整。
与函数联系：方程组的解 = 两条直线交点的横纵坐标。

解题套路

1. 某个未知数系数为 1 时，优先用代入法；系数成倍数关系时，优先用加减法。
1. 加减法先「凑系数」：把同一未知数的系数变成相同或互为相反数再相加减。
1. 应用题三类型：和差倍分（直接列）、配套问题（按比例设份数）、图表信息（从表格读数据列方程）。

易错警示

- ✕ 加减消元时只乘了含未知数的项，漏乘常数项。
- ✕ 解出 x 后忘记代回求 y，只答一半。
- ✕ 应用题中两个未知数单位不统一就列方程。

典型例题

【例】解方程组：2x + 3y = 8 ①， 3x − y = 1 ②
【解】由②得 y = 3x − 1，代入①：2x + 3(3x − 1) = 8，即 11x = 11，x = 1。把 x = 1 代入②得 y = 2。∴ x = 1，y = 2。【也可用加减法：②×3 得 9x − 3y = 3，与①相加消去 y】

07 一元二次方程的解法

前置：因式分解 · 完全平方公式→通向：二次函数 · 根与系数关系
数与代数 · 方程与不等式

核心知识

四种解法：直接开平方（形如 (x+m)² = n，n ≥ 0）、因式分解法（最快捷）、配方法（通用）、公式法（万能）。
求根公式：x = [−b ± √(b² − 4ac)] / 2a（a ≠ 0 且 Δ = b² − 4ac ≥ 0）。
判别式：Δ > 0 有两个不相等的实数根；Δ = 0 有两个相等的实数根；Δ < 0 无实数根。
根与系数（部分教材选学）：x₁ + x₂ = −b/a，x₁·x₂ = c/a。

解题套路

1. 用公式法前先把方程化为一般式 ax² + bx + c = 0，准确确定 a、b、c 及其符号。
1. 因式分解法解方程必须先移项使右边为 0，再分解「两个因式之积 = 0」。
1. 选择顺序：能开方先开方，能分解先分解，都不行再配方或用公式。

易错警示

- ✕ 没有化为一般式就直接代入公式。
- ✕ 两边约去含 x 的因式，丢掉 x = 0 这个根（必须先移项提出公因式）。
- ✕ Δ < 0 时仍套公式写出根。

典型例题

【例】解方程：2x² − 4x − 6 = 0
【解】两边除以 2：x² − 2x − 3 = 0，因式分解得 (x − 3)(x + 1) = 0。∴ x − 3 = 0 或 x + 1 = 0，即 x₁ = 3，x₂ = −1。【公式法验证：a=2, b=−4, c=−6，Δ = 16 + 48 = 64，x = (4 ± 8)/4，同样得 3 和 −1】

08 一元二次方程的应用

前置：方程解法 · 舍根判断→通向：二次函数最值应用
数与代数 · 方程与不等式

核心知识

增长率模型：a(1 + x)ⁿ = b：原来为 a，平均变化率 x，经 n 次变化后为 b；两次变化即 a(1+x)² = b。
面积模型：「长 × 宽 = 面积」列方程；小路问题用「平移法」——把路平移到边上，剩余部分拼成新矩形。
利润模型：总利润 = 单件利润 × 销量；常设降价 x 元，销量增加 kx 件。
解后双检：根是否为增根；是否符合实际（边长、人数、降价率非负且合理）。

解题套路

1. 增长率题分清「增长的基数」：第二年是在第一年的结果上继续增长。
1. 面积题先画图、设未知数，列方程后立刻想「哪个根要舍」。
1. 降价促销：利润 = (原利润 − x)(原销量 + kx)，列方程前先检查各量意义。

易错警示

- ✕ 不舍去不合题意的根（如边长为负）。
- ✕ 连续两次增长误用 a(1 + 2x)，正确是 a(1 + x)²。
- ✕ 忘记降价率 x 应满足 0 < x < 1。

典型例题

【例】某商品原价 100 元，连续两次降价后售价为 81 元，求平均每次降价的百分率。
【解】设平均每次降价率为 x，则 100(1 − x)² = 81，(1 − x)² = 0.81，1 − x = ±0.9。∴ x₁ = 0.1 = 10%，x₂ = 1.9（舍去，降价率不能超过 1）。∴ 平均每次降价 10%。

09 一次函数图象与性质

前置：平面直角坐标系 · 待定系数法→通向：一次函数与方程不等式 · 方案选择
数与代数 · 函数

核心知识

定义与图象：y = kx + b（k ≠ 0）的图象是一条直线；k 定方向（增减），b 定与 y 轴的交点 (0, b)。
增减性：k > 0 时 y 随 x 增大而增大；k < 0 时 y 随 x 增大而减小。
两点法画图：取 (0, b) 与 (−b/k, 0) 两点连线即可。
待定系数法：把两个已知点的坐标代入 y = kx + b，解二元一次方程组求出 k、b。

解题套路

1. 求解析式：找两个已知点 → 代入 → 解方程组，最后检验。
1. 比较函数值大小：k > 0 时 x 大者 y 大；也可以看「哪段图象位置更高」。
1. 方案选择：分别写出两种方案的费用 y 关于 x 的函数，作差比较、找临界点。

易错警示

- ✕ k、b 的几何意义看反：k 管升降（斜率），b 管与 y 轴交点。
- ✕ 忽略 k ≠ 0 的限制。
- ✕ 正比例函数 y = kx 是一次函数 b = 0 的特例，不要当成两种无关的函数。

典型例题

【例】直线 y = kx + b 经过点 (1, 2) 和 (−1, 4)，求它的解析式，并说明 y 随 x 的变化情况。
【解】代入得 k + b = 2，−k + b = 4。两式相加：2b = 6，b = 3；则 k = −1。∴ y = −x + 3。∵ k = −1 < 0，∴ y 随 x 增大而减小。

10 一次函数与方程、不等式

前置：一次函数图象→通向：函数建模 · 分段计费问题
数与代数 · 函数

核心知识

方程角度：kx + b = 0 的解 = 直线与 x 轴交点的横坐标。
不等式角度：kx + b > 0 的解集 = 直线在 x 轴上方部分所对应的 x 的范围。
方程组角度：两条直线的交点坐标 = 对应二元一次方程组的解。
本质统一：函数图象把「解方程」「解不等式」变成「看图找位置」——数形结合。

解题套路

1. 看图写解集：先找与 x 轴交点，再判断图象在 x 轴上方还是下方。
1. 求两直线交点：把两个解析式联立成方程组求解。
1. 分段计费（水电费、出租车）：先分段写函数关系，再按自变量的范围代入计算。

易错警示

- ✕ 只会代数计算，不会从图象直接读出解集（数形结合意识弱）。
- ✕ 「图象在上方」对应「>0」、在下方对应「<0」的对应关系记反。

典型例题

【例】已知直线 y = 2x + 4。① 求它与 x 轴的交点坐标；② 直接写出不等式 2x + 4 > 0 的解集。
【解】① 令 y = 0：2x + 4 = 0，x = −2，∴ 交点为 (−2, 0)。② 直线在 x 轴上方的部分对应 x > −2，∴ 解集为 x > −2。【方程的解、不等式的解集、图象位置，是同一件事的三种说法】

11 反比例函数与 k 的几何意义

前置：双曲线图象 · 矩形面积→通向：与一次函数综合 · 反比例实际问题
数与代数 · 函数

核心知识

定义与图象：y = k/x（k ≠ 0），图象是双曲线；k > 0 在第一、三象限，k < 0 在第二、四象限。
增减性：必须在「每个象限内」讨论：k > 0 时在每个象限内 y 随 x 增大而减小；k < 0 时增大。
k 的几何意义：过双曲线上任一点向两坐标轴作垂线，围成的矩形面积 = |k|；两个三角形面积 = |k|/2。
与一次函数综合：联立两个解析式解方程组求交点；双曲线两支上的交点关于原点对称。

解题套路

1. 已知双曲线上一点求 k：直接用 k = 横坐标 × 纵坐标。
1. 面积类题直接用 |k|，注意「矩形面积 = |k|」「三角形面积 = |k|/2」的区别。
1. 比较大小：先判断点所在象限，同象限内用增减性，跨象限直接按 y 值正负比。

易错警示

- ✕ 说成「在整个定义域内 y 随 x 增大而减小」——必须强调「在每个象限内」。
- ✕ 矩形面积写成 k，忘加绝对值（k < 0 时出错）。
- ✕ 双曲线无限接近坐标轴但永不相交，画图不要画成「碰到轴」。

典型例题

【例】反比例函数 y = k/x 的图象经过点 A(2, 3)。① 求 k 的值；② 点 B(a, −2) 也在图象上，求 a；③ 求过点 A 向两坐标轴作垂线所围成的矩形面积。
【解】① k = 2 × 3 = 6。② 6 = a × (−2)，∴ a = −3。③ 矩形面积 = |k| = 6。【k = xy 是反比例函数最本质的关系】

12 二次函数综合

前置：一元二次方程 · 顶点式→通向：中考压轴题 · 动点与面积最值
数与代数 · 函数

核心知识

三种形式：一般式 y = ax² + bx + c；顶点式 y = a(x − h)² + k，顶点 (h, k)；交点式 y = a(x − x₁)(x − x₂)，与 x 轴交于 (x₁,0)、(x₂,0)。
顶点与对称轴：对称轴 x = −b/(2a)，顶点纵坐标 = (4ac − b²)/(4a)。
最值：a > 0 开口向上，顶点处取最小值；a < 0 开口向下，顶点处取最大值；自变量限定范围时，最值可能出现在端点。
与方程关系：抛物线与 x 轴交点的横坐标 = ax² + bx + c = 0 的根（需 Δ ≥ 0）。

解题套路

1. 求解析式按条件选形式：已知三点用一般式；已知顶点用顶点式；已知与 x 轴两交点用交点式。
1. 最值三查：一查开口方向，二查对称轴是否在取值范围内，三查端点处的函数值。
1. 几何综合（面积最大）：设动点坐标 → 表示线段长 → 列面积函数 → 用顶点求最值。

易错警示

- ✕ 取最值时不检查顶点横坐标是否在自变量取值范围内。
- ✕ a < 0 时说成「有最小值」。
- ✕ 顶点纵坐标公式 (4ac − b²)/(4a) 代错符号。

典型例题

【例】求抛物线 y = x² − 4x + 3 的顶点坐标、对称轴，以及它与 x 轴的交点坐标。
【解】配方：y = (x − 2)² − 1，∴ 顶点为 (2, −1)，对称轴为直线 x = 2。令 y = 0：(x − 1)(x − 3) = 0，∴ 交点为 (1, 0) 和 (3, 0)。【三种信息各用一种形式最快：顶点用顶点式，交点用因式分解】

13 平行线的性质与判定

前置：三线八角 · 对顶角→通向：平行四边形 · 相似与比例
图形与几何 · 相交线与平行线

核心知识

三线八角：同位角（F 型）、内错角（Z 型）、同旁内角（U 型）——先认位置，再谈数量。
判定（角 → 平行）：同位角相等 / 内错角相等 / 同旁内角互补 ⇒ 两直线平行。
性质（平行 → 角）：两直线平行 ⇒ 同位角相等、内错角相等、同旁内角互补。
平行公理：过直线外一点，有且只有一条直线与已知直线平行。

解题套路

1. 分清方向：由「角的数量关系」推「平行」是判定；由「平行」推「角」是性质。
1. 遇拐点（折线、铅笔头）：过拐点作平行线，把一个角拆成两段分别转移。
1. 求角度先找「位置关系」，再转化为「数量关系」列式或列方程。

易错警示

- ✕ 判定与性质的条件、结论写反。
- ✕ 同旁内角误用「相等」（正确是互补）。

典型例题

【例】AB∥CD，点 P 在两平行线之间，连接 PA、PC，已知 ∠A = 40°，∠C = 30°（∠APC 是折线拐角）。求 ∠APC。
【解】过 P 作 PE∥AB，则 PE∥CD。∴ ∠APE = ∠A = 40°，∠CPE = ∠C = 30°（两直线平行，内错角相等）。∴ ∠APC = 40° + 30° = 70°。【拐点问题通法：过拐点作平行线，把拐角拆到两边】

14 全等三角形的判定与性质

前置：三角形边角关系 · 内角和→通向：等腰三角形 · 平行四边形
图形与几何 · 三角形

核心知识

五种判定：SSS、SAS、ASA、AAS、HL（HL 仅适用于直角三角形）。
性质：全等三角形对应边相等、对应角相等（周长相等、面积相等）。
不能判定：SSA（边边角）、AAA（三角）不能判定全等。
隐藏条件：公共边、公共角、对顶角、平行线的内错角——找条件时先找这些。

解题套路

1. 证线段（角）相等：转化为证它们所在的两个三角形全等。
1. 按「边 → 角」顺序清点已知条件，缺什么补什么（常作辅助线构造 SAS 或 SSS）。
1. 书写规范：对应顶点写在对应位置，大括号列三个条件，末尾写判定依据（如 SAS）。

易错警示

- ✕ 误用 SSA 或 AAA 判定全等。
- ✕ 对应顶点找错，导致对应边写错。
- ✕ 只写「△ABD ≌ △ACD」不写判定依据，要扣分。

典型例题

【例】已知 AB = AC，AD 平分 ∠BAC。求证：BD = CD。
【解】∵ AD 平分 ∠BAC，∴ ∠BAD = ∠CAD。在 △ABD 与 △ACD 中：AB = AC，∠BAD = ∠CAD，AD = AD（公共边）。∴ △ABD ≌ △ACD（SAS），∴ BD = CD（全等三角形对应边相等）。

15 等腰三角形的性质与判定

前置：全等三角形 · 轴对称→通向：等边三角形 · 相似三角形
图形与几何 · 三角形

核心知识

性质：等边对等角（两腰相等 ⇒ 两底角相等）；三线合一——顶角平分线、底边上的中线、底边上的高互相重合。
判定：等角对等边；三边相等的三角形是等边三角形；有一个角是 60° 的等腰三角形是等边三角形。
等边三角形：三条「三线合一」，每个内角都是 60°。
分类意识：没有图的「已知两边求周长」题，必须检验能否构成三角形。

解题套路

1. 见「中线 + 两边相等」想三线合一：作底边的高（或中线）常能构造全等或直角三角形。
1. 求角度时设未知角，用内角和 180° 列方程。
1. 两边求周长：分别假设每条边是腰，逐一检验「两边之和 > 第三边」。

易错警示

- ✕ 把三线合一用在非等腰三角形上。
- ✕ 忘记检验「4, 4, 9」这类不能构成三角形的情况。

典型例题

【例】等腰三角形的两边长分别为 4 和 9，求它的周长。
【解】若腰长为 4：三边为 4, 4, 9。∵ 4 + 4 = 8  9，成立。∴ 周长 = 9 + 9 + 4 = 22。

16 勾股定理及其逆定理

前置：直角三角形 · 平方根→通向：解直角三角形 · 两点间距离公式
图形与几何 · 三角形

核心知识

勾股定理：直角三角形两直角边为 a、b，斜边为 c，则 a² + b² = c²。
逆定理：若三角形三边满足 a² + b² = c²（c 为最长边），则它是直角三角形。
常用勾股数：3, 4, 5；5, 12, 13；6, 8, 10；7, 24, 25（同倍数放大依然成立）。
两个重要结论：直角三角形斜边上的中线等于斜边的一半；30° 角所对的直角边等于斜边的一半。

解题套路

1. 折叠问题：抓住「折前折后对应边、对应角相等」，设未知数，在直角三角形里用勾股列方程。
1. 最短路径（圆柱 / 圆锥侧面）：把侧面展开成平面，「两点之间线段最短」，再用勾股求。
1. 判定直角：把三边代入，验证「两较短边的平方和 = 最长边的平方」。

易错警示

- ✕ 斜边找错：斜边必须是直角所对的最长边。
- ✕ 已知两边 3 和 4 求第三边，默认斜边是 4——4 也可能是直角边，要分类。
- ✕ 折叠题不设未知数、不找等量关系就硬算。

典型例题

【例】直角三角形的两边长分别为 3 和 4，求第三边的长。
【解】情形一：3、4 都是直角边，则斜边 = √(3² + 4²) = √25 = 5。情形二：4 是斜边，则第三边 = √(4² − 3²) = √7。∴ 第三边长为 5 或 √7。【分类讨论：4 可能是斜边，也可能不是】
