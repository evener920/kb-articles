> “
> 一个能接管第三方流媒体站点、用原生播放器硬解播放的 TV 优先 Android 应用，自带广告过滤、WARP 隧道和 IPTV。
> 
Github地址
**https://github.com/fmhyplay/android**
![](assets/415feb00ed728145-1.jpg)
功能特性
- 站点接管：打开你选的流媒体站，自动嗅探 HLS/DASH/FLV 流，切到 ExoPlayer 硬件解码，页面上的选集、清晰度、字幕/配音按钮同步映射到播放器里，不用退回网页操作
- 广告拦截：域名级过滤，弹窗广告直接丢掉，假链接新开标签页处理
- 投屏三选一：同 WiFi 下手机投给电视（电视端装 FMHYPlay 最佳，自带 cookie 和 WARP 穿透；Chromecast/Google TV 免装应用但手机中转；DLNA/UPnP 兼容三星 LG 索尼 Kodi）
- 追剧追番：底部选集条、上一集/下一集、自动连播；支持 TheIntroDB 和 AniSkip 的片头片尾跳过；字幕配音切换记忆
- 播放器细节：断点续播（10 秒存一次进度）、OpenSubtitles 字幕自动匹配同步、音量增强 +12dB、对话增强、调试浮层看码率帧率硬软解状态、画中画、长按 2 倍速
- IPTV：内置 iptv-org 11000+ 公开频道，按国别分类，后台检测失效源；支持自建 m3u8、Xtream Codes、Stalker 门户，频道过滤和 PIN 固定
- 网络隐私：应用级 Cloudflare WARP（userspace WireGuard，不用系统 VPN 权限），局域网直连不走隧道；无账号、无统计、无遥测
- 多语言：英印西葡阿德印尼，随系统切换，阿拉伯语 RTL 适配
怎么用
TV 端：Android TV、Google TV、Fire TV 都能装，Fire TV 用 Downloader 输代码 9828006。支持遥控器浏览、打字或语音搜索、续播列表。
手机端：同一个 App，触屏操作。
安装直接去 GitHub Releases 下 APK，项目本身不用 Gradle，纯 Java 加 Android SDK 命令行工具，源码 clone 下来两条命令就能编译。发布是 GitHub Actions 自动构建签名，带校验和。
隐私方面没账号、没分析、没遥测，WARP 隧道只走应用自身的流量。MIT 协议开源，不托管任何媒体，跟 FMHY、Cloudflare 那些也没隶属关系。
